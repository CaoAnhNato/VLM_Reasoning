### 4.1 Adapter Pre-Extraction & Unblurred Isotropic Slicing (`vintern_adapter.py`)
Given native RGB image $I$ of pixel size $(W, H)$ and cached unwarped `vit_embeds` (`[N_tiles, P_tile, D]`) with spatial tile grid $(g_x, g_y)$ ($B = 1$ if $N_{\text{tiles}} == 1$ else $N_{\text{tiles}} - 1$; fallback $(g_x, g_y) = (B, 1)$ when $B \ne g_x g_y$; $p_{\text{side}} = \text{round}(\sqrt{P_{\text{tile}}})$, lattice shape $(H_g, W_g) = (p_{\text{side}} g_y, \, p_{\text{side}} g_x)$):
1. **Unwarped Spatial Patch Lattice**: Reshape `vit_embeds[:B].detach()` (without mutating `self._cached_vit_embeds`) into `patch_embeds` $V \in \mathbb{R}^{H_g \times W_g \times D}$ where tile $b \in \{0, \dots, B-1\}$ maps to rows $[t_y p_{\text{side}}, (t_y + 1) p_{\text{side}})$ and columns $[t_x p_{\text{side}}, (t_x + 1) p_{\text{side}})$ with $t_y = \lfloor b / g_x \rfloor$, $t_x = b \bmod g_x$.
2. **Windowed $SO(2)$ Structure-Tensor Harmonic Eigenvalue (`lefkimmiatis2013hessian` Thm. 2, `bruna2013scattering`)**: Let $I_Y \in [0, 1]^{H \times W}$ be channel-averaged `float32` RGB luminance. Compute zero-padded forward finite differences (`F.pad` default constant `0.0` mode so 2D 4-tuple padding is supported in PyTorch):
   $$I_x = \begin{cases} \text{pad}(I_Y[:, 1:] - I_Y[:, :-1], \, (0, 1)) & \text{if } W > 1 \\ \mathbf{0}_{H \times W} & \text{if } W \le 1 \end{cases}, \qquad I_y = \begin{cases} \text{pad}(I_Y[1:, :] - I_Y[:-1, :], \, (0, 0, 0, 1)) & \text{if } H > 1 \\ \mathbf{0}_{H \times W} & \text{if } H \le 1 \end{cases}$$
   Pool the symmetric $2 \times 2$ gradient outer-product components $J_{xx} = \text{pool}(I_x^2)$, $J_{yy} = \text{pool}(I_y^2)$, and $J_{xy} = \text{pool}(I_x I_y)$ onto $(H_g, W_g)$ via `F.adaptive_avg_pool2d`, and form the 1-homogeneous $SO(2)$-invariant harmonic eigenvalue `optical_energy` on `vit_embeds.device`:
   $$\mathcal{E}_{\text{ST}}(u) = \sqrt{\dfrac{\max\big(0.0, \; J_{xx}(u) J_{yy}(u) - J_{xy}(u)^2\big)}{\max\big(0.0, \; J_{xx}(u) + J_{yy}(u)\big) + 10^{-12}}} \in \mathbb{R}_{\ge 0}^{H_g \times W_g}$$
3. **Prompt-Centered Layer-0 Query Embeddings**: Tokenize `question.strip()` (`add_special_tokens=False`) into $M$ token IDs. If $M == 0$ or `get_input_embeddings` is unavailable, set `query_embeds = None`; else look up `q_raw = embed_layer(q_ids).squeeze(0).float()` (`[M, D]`) and subtract the mean `float32` Layer-0 embedding of `PROMPT_INSTRUCTION` (`[1, D]`) to obtain `query_embeds` $E_Q \in \mathbb{R}^{M \times D}$.
4. **100% Unblurred In-Bounds Isotropic Native-RGB Crop Encoding (`encode_transient_roi_crops`, `extract_foveated_roi_crops`)**:
   - `extract_foveated_roi_crops` calls `boxes, j1_star, _ = self.engine.foveate(optical_energy, patch_embeds, query_embeds=query_embeds)`. If `not boxes` or `j1_star <= 1e-6`, return `None`. Otherwise map each lattice box `(i1, j1, i2, j2)` in `boxes` to pixel coordinates `(round(j1 * W / W_g), round(i1 * H / H_g), round(j2 * W / W_g), round(i2 * H / H_g))` and pass the list to `encode_transient_roi_crops(image, pixel_boxes, max_tiles=2)`.
   - Inside `encode_transient_roi_crops(self, image, bboxes, max_tiles=2)`: maintain `remaining = max_tiles` and `rgb_img = image.convert("RGB")` of size $(W, H)$. For each `bbox = (bx1, by1, bx2, by2)` in `bboxes` while `remaining > 0`:
     1. Canonicalize `cbx1, cbx2 = round(min(bx1, bx2)), round(max(bx1, bx2))` and `cby1, cby2 = round(min(by1, by2)), round(max(by1, by2))`, `raw_w = max(2, cbx2 - cbx1)`, `raw_h = max(2, cby2 - cby1)`, expand by `context_margin = 0.15` (`pad_x = round(0.15 * raw_w)`, `pad_y = max(round(0.15 * raw_h), 2)`), and clamp `[x1, x2] x [y1, y2]` into `[0, W] x [0, H]` (`min_dx = min(2, W)`, `min_dy = min(2, H)`, $\Delta_x = \max(\text{min\_dx}, x_2 - x_1)$, $\Delta_y = \max(\text{min\_dy}, y_2 - y_1)$).
     2. Select aspect-matched grid $(g_x^*, g_y^*) = \text{DynamicMultiTileROICropper}(\text{target\_size}=\text{self.force\_image\_size}, \, \text{max\_tiles}=\text{remaining}).\text{select\_grid}(\Delta_x, \Delta_y)$ (`ye2023ureader`, `dehghani2023patch`).
     3. Compute isotropic unit side $s_{\text{unit}} = \max(\Delta_x / g_x^*, \, \Delta_y / g_y^*)$, apply the smooth minimum patch-scale floor $s_{\text{min}} = \min(32.0, \min(W, H))$ with $s_{\text{floor}} = s_{\text{min}} + \frac{0.05 \min(W, H)}{1 + \exp(-0.05 (\max(\Delta_x, \Delta_y) - s_{\text{min}}))}$ and $s_{\text{unit}} \leftarrow \min\big(\max(s_{\text{unit}}, s_{\text{floor}}), \, W / g_x^*, \, H / g_y^*\big)$, and form enclosing in-bounds canvas dimensions $S_x = \min\big(W, \, \max(\Delta_x, \, s_{\text{unit}} g_x^*)\big)$ and $S_y = \min\big(H, \, \max(\Delta_y, \, s_{\text{unit}} g_y^*)\big)$.
     4. Center on $(\mu_x, \mu_y) = \big(0.5(x_1 + x_2), \, 0.5(y_1 + y_2)\big)$ and shift cleanly inside `[0, W] x [0, H]` (`shao2024visualcot` p. 6; `sx1 = max(0.0, min(W - S_x, mu_x - 0.5 * S_x))`, `sy1 = max(0.0, min(H - S_y, mu_y - 0.5 * S_y))`), slicing `g_x^* * g_y^*` **100% unblurred** native-RGB sub-tiles (`0` `GaussianBlur`, `0` border mirror-reflection; `raghu2021vision`) resized via `BICUBIC` to `(self.force_image_size, self.force_image_size)`, and decrement `remaining -= g_x^* * g_y^*`. Stack all `N_crop <= max_tiles` tiles and encode via `self.model.extract_feature(pixel_values)` in `bfloat16` without mutating `self._cached_vit_embeds`.

### 4.2 Core Variational Foveation Equations (`src/nevfe/core/engine.py`)

- **(Eq. 1) Canonical Gibbs Structure-Tensor Optical Distribution (`compute_bregman_optical_distribution`)**:
  Given `optical_energy` $\mathcal{E}_{\text{ST}} \in \mathbb{R}^{H_g \times W_g}$ (requiring `.dim() == 2`, signature `compute_bregman_optical_distribution(optical_energy: torch.Tensor, tau_v: float = 1e-6) -> torch.Tensor`), sanitize via `torch.nan_to_num(optical_energy.float(), nan=0.0, posinf=0.0, neginf=0.0)` and clamp $\mathcal{E}(u) = \max(0.0, \mathcal{E}_{\text{ST}}(u))$. If `e.numel() == 0`, return `e`. Apply 0-homogeneous peak scaling $\tilde{\mathcal{E}}(u) = \mathcal{E}(u) / \max\big(1.0, \, \max_{v \in \Omega} \mathcal{E}(v)\big) \in [0.0, 1.0]$ (an exact identity whenever $\max \mathcal{E} \le 1.0$, preventing `float32` variance-square overflow up to `FLT_MAX` and `float32` mean-subtraction ULP amplification on large constant inputs), subtract the unique spatial Bregman centroid $\bar{\mathcal{E}} = \text{mean}(\tilde{\mathcal{E}})$ (`banerjee2005bregman` Prop. 1; `nielsen2009bregman` Thm. 2.1), compute $\Delta \tilde{\mathcal{E}}(u) = \tilde{\mathcal{E}}(u) - \bar{\mathcal{E}}$ and unregularized standard deviation $\sigma_{\mathcal{E}} = \sqrt{\max\big(0.0, \, \text{mean}(\Delta \tilde{\mathcal{E}}^2)\big)}$, and map via the Legendre-dual canonical Gibbs Softmax (`nielsen2009bregman` Sec. 2.2):
  $$z_{\text{opt}}(u) = \begin{cases} \dfrac{\Delta \tilde{\mathcal{E}}(u)}{\max(\sigma_{\mathcal{E}}, \, \tau_v)} & \text{if } \sigma_{\mathcal{E}} > \tau_v \\ 0.0 & \text{if } \sigma_{\mathcal{E}} \le \tau_v \text{ (uniform / monochromatic boundary)} \end{cases}, \qquad P_{\text{opt}}(u) = \text{Softmax}_{u \in \Omega}\big(z_{\text{opt}}(u)\big) \in \Delta^{H_g W_g - 1}$$

- **(Eq. 2) Bregman-Centered Layer-0 Lexical Spatial Distribution (`compute_lexical_spatial_distribution`)**:
  Given `patch_embeds` $V \in \mathbb{R}^{H_g \times W_g \times D}$ (requiring `.dim() == 3`) and `query_embeds` $E_Q \in \mathbb{R}^{M \times D}$ (`Optional[torch.Tensor]`), sanitize both via `torch.nan_to_num(..., nan=0.0, posinf=0.0, neginf=0.0)` in `float32`.
  - *Boundary condition ($E_Q$ is `None`, `.dim() != 2`, $M == 0$, $D == 0$, or $H_g W_g == 0$)*: Return exact uniform distribution $P_{\text{lex}}(u) = \frac{1.0}{\max(1, H_g W_g)} \in \mathbb{R}^{H_g \times W_g}$ (if $E_Q$ is a 2D tensor with $E_Q.\text{shape}[1] \ne D$, raise `ValueError`).
  - Otherwise, apply 0-homogeneous peak scaling $\tilde{V} = V / \max\big(1.0, \, \max |V|\big) \in [-1.0, 1.0]$ and $\tilde{E}_Q = E_Q / \max\big(1.0, \, \max |E_Q|\big) \in [-1.0, 1.0]$, remove the spatial register centroid $\bar{V} = \frac{1}{H_g W_g}\sum_{v \in \Omega} \tilde{V}(v)$ (`darcet2024registers`), compute $\Delta \tilde{V}(u) = \tilde{V}(u) - \bar{V}$ with Euclidean norms $r_V(u) = \|\Delta \tilde{V}(u)\|_2$ and $r_E(m) = \|\tilde{E}_{Q,m}\|_2$, apply dimension-scaled `float32` ULP gate $\tau_D = \tau_v \sqrt{\max(1, D)}$ ($\hat{V}(u) = \Delta \tilde{V}(u) / \max(r_V(u), \tau_D)$ if $r_V(u) > \tau_D$ else $\mathbf{0}$, and $\hat{E}_m = \tilde{E}_{Q,m} / \max(r_E(m), \tau_v)$ if $r_E(m) > \tau_v$ else $\mathbf{0}$), evaluate peak cross-modal cosine alignment $c_Q(u) = \max_{1 \le m \le M} \langle \hat{V}(u), \hat{E}_m \rangle \in [-1, 1]$, compute $\Delta c_Q = c_Q - \text{mean}(c_Q)$ and unregularized $\sigma_Q = \sqrt{\max(0.0, \text{mean}(\Delta c_Q^2))}$, and map via matched unit-variance Softmax:
    $$z_Q(u) = \begin{cases} \dfrac{\Delta c_Q(u)}{\max(\sigma_Q, \, \tau_v)} & \text{if } \sigma_Q > \tau_v \\ 0.0 & \text{if } \sigma_Q \le \tau_v \end{cases}, \qquad P_{\text{lex}}(u) = \text{Softmax}_{u \in \Omega}\big(z_Q(u)\big) \in \Delta^{H_g W_g - 1}$$

- **(Eq. 3) Exponential `e`-Geodesic Variational Posterior (`compute_variational_posterior`)**:
  Given variance-matched $P_{\text{opt}}, P_{\text{lex}} \in \Delta^{H_g W_g - 1}$, scalar `gamma_param` $\gamma \in [0.0, 1.0]$ (`Optional[float] = None`, defaulting via `AlgorithmConfig().gamma_param`), and ablation flags `(comp_a, comp_b)`, resolve $\gamma_{\text{eff}} = \text{clamp}(\gamma, 0.0, 1.0)$ if $\text{comp\_a} \wedge \text{comp\_b}$, $1.0$ if $\text{comp\_a} \wedge \neg\text{comp\_b}$, and $0.0$ if $\neg\text{comp\_a} \wedge \text{comp\_b}$.
  - *Boundary condition ($H_g W_g == 0$ or $\neg\text{comp\_a} \wedge \neg\text{comp\_b}$)*: Return uniform $P_\gamma^*(u) = \frac{1.0}{\max(1, H_g W_g)}$.
  - Otherwise, sanitize inputs via `torch.nan_to_num(..., nan=0.0, posinf=0.0, neginf=0.0)` and compute the unique left-sided KL-Bregman `e`-geodesic posterior (`nielsen2009bregman` Thm. 2.2 & 3.2) with $\epsilon = 10^{-12}$:
    $$P_\gamma^*(u) = \text{Softmax}_{u \in \Omega}\Big(\gamma_{\text{eff}} \ln \max(P_{\text{opt}}(u), \epsilon) + (1.0 - \gamma_{\text{eff}}) \ln \max(P_{\text{lex}}(u), \epsilon)\Big)$$

- **(Eq. 4a) Self-Dual Order-$1/2$ Rényi (Bhattacharyya-Hellinger) Partition Functional (`select_renyi_foveal_subwindow`)**:
  Given `posterior_2d` $P \in \Delta^{H_g W_g - 1}$ (requiring `.dim() == 2`, signature `select_renyi_foveal_subwindow(posterior_2d: torch.Tensor, eps_k: float = 1e-6, eps: float = 1e-12) -> Tuple[Tuple[int, int, int, int], float, float, float]`), sanitize via `torch.nan_to_num(posterior_2d.float(), nan=0.0, posinf=0.0, neginf=0.0)`, clamp $\ge 0.0$, peak-scale by $\max(1.0, \max P)$ when $H_g W_g > 0$, and normalize by its sum if $> \epsilon$ (else uniform $\frac{1.0}{\max(1, H_g W_g)}$).
  - *Boundary condition ($H_g W_g \le 1$)*: Return `((0, 0, H_g, W_g), 0.0, 1.0, 1.0)`.
  - Otherwise, form the zero-padded 2D summed-area table $S \in \mathbb{R}^{(H_g+1)\times(W_g+1)}$ and evaluate all nonempty axis-aligned subwindows $C = [i_1, i_2) \times [j_1, j_2)$ via `torch.triu_indices(..., offset=1)` with captured mass $p(C)$ and area fraction $a(C) = \frac{(i_2 - i_1)(j_2 - j_1)}{H_g W_g}$. Over the admissible zoom cone $\mathcal{C}_{\text{adm}} = \{C : p(C) > a(C) + \epsilon_k \;\wedge\; \epsilon_k \le a(C) \le 0.5\}$ ($\epsilon_k = 10^{-6}$), clamp $p_{\text{cl}}, a_{\text{cl}} \in [\epsilon_k, 1.0 - \epsilon_k]$. To avoid IEEE-754 `float32` catastrophic cancellation near $\text{BC} \approx 1.0$, compute the algebraically identical squared binary Hellinger distance $h^2(C) = 1 - \text{BC}_{\text{part}}(C)$ (`sason2016fdivergence` Eq. (2)) and Order-$1/2$ Rényi partition divergence (`vanerven2014renyi` Thm. 2; `sason2016fdivergence` Eq. (17)) via `log1p`:
    $$h^2(C) = \text{clamp}\!\left(0.5 \cdot \Big[\big(\sqrt{p_{\text{cl}}} - \sqrt{a_{\text{cl}}}\big)^2 + \big(\sqrt{1.0 - p_{\text{cl}}} - \sqrt{1.0 - a_{\text{cl}}}\big)^2\Big], \; 0.0, \; 1.0 - \epsilon_k\right)$$
    $$J_{\text{raw}}(C) = \text{nan\_to\_num}\Big(-\text{log1p}\big(-h^2(C)\big) \cdot 2.0, \; \text{nan}=0.0, \, \text{posinf}=0.0, \, \text{neginf}=0.0\Big), \qquad J_{1/2}(C) = \begin{cases} \max(0.0, \, J_{\text{raw}}(C)) & \text{if } C \in \mathcal{C}_{\text{adm}} \\ 0.0 & \text{otherwise} \end{cases}$$
    *(AST Literal Implementation Rule: implement $J_{\text{raw}}(C)$ in `engine.py` using `-torch.log1p(-h_sq) * 2.0` so only allowed literals `0.5, 0.0, 1.0, 2.0` appear in the AST.)* Let $C^* = \arg\max_C J_{1/2}(C)$ and $J^* = J_{1/2}(C^*)$. If $J^* \le \epsilon_k$, return `((0, 0, H_g, W_g), 0.0, 1.0, 1.0)`; else return `((i_1^*, j_1^*, i_2^*, j_2^*), float(J^*), float(p(C^*)), float(a(C^*)))`.

- **(Eq. 4b) Exact KL I-Projection Conditional Posterior Deflation (`deflate_conditional_posterior` & `NEVFEEngine.foveate`)**:
  - Define `deflate_conditional_posterior(posterior_2d: torch.Tensor, primary_box: Tuple[int, int, int, int], eps_k: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`: sanitize `posterior_2d` (`nan=0.0, posinf=0.0, neginf=0.0`), clamp $\ge 0.0$, peak-scale by $\max(1.0, \max P)$ when $H_g W_g > 0$, and normalize onto $\Delta^{H_g W_g - 1}$ (`p`; if $H_g W_g == 0$, return `p`). Clamp `primary_box` indices $(i_1, j_1, i_2, j_2)$ to $[0, H_g] \times [0, W_g]$, compute $p_1 = \sum_{u \in C_1^*} p(u)$, $a_1 = \frac{(i_2 - i_1)(j_2 - j_1)}{H_g W_g}$, and uniform cell mass $u_0 = \frac{1.0}{\max(1, H_g W_g)}$.
    - *Boundary condition ($a_1 \le 0.0$ or $1.0 - p_1 \le \epsilon_k$ or $1.0 - a_1 \le \epsilon_k$)*: Return uniform $\text{full\_like}(p, u_0)$ (so $J_2^* = 0.0$ when $C_1^*$ captures all mass or covers $\Omega$).
    - Otherwise, compute the unique KL I-projection $\tilde{P}^{(2)} = \arg\min_{Q \in \Delta : Q|_{C_1^*} = u_0} D_{\text{KL}}(Q \parallel P)$ onto the $C_1^*$-equilibrium linear submanifold:
      $$\tilde{P}_{\text{raw}}^{(2)}(u) = \begin{cases} u_0 & \text{if } u \in C_1^* \\[4pt] \dfrac{1.0 - a_1}{\max(1.0 - p_1, \, \epsilon_k)} \, p(u) & \text{if } u \notin C_1^* \end{cases}, \qquad \tilde{P}^{(2)}(u) = \dfrac{\tilde{P}_{\text{raw}}^{(2)}(u)}{\max\big(\sum_{v \in \Omega} \tilde{P}_{\text{raw}}^{(2)}(v), \, \epsilon\big)}$$
      Whenever $p$ is uniform outside $C_1^*$, $\tilde{P}^{(2)} \equiv u_0$ identically over $\Omega$, guaranteeing $J_{1/2}(\tilde{P}^{(2)}) = 0.0$ (zero spurious secondary crop on single-locus scenes).
  - Expose `NEVFEEngine.foveate(self, optical_energy, patch_embeds, query_embeds=None) -> Tuple[List[Tuple[int, int, int, int]], float, torch.Tensor]`: execute `(Eq. 1) -> (Eq. 2) -> (Eq. 3) -> (Eq. 4a)` to obtain `(box1, j1_star, _, _)`. If `j1_star <= 1e-6`, return `([], 0.0, posterior_2d)` (e.g., uniform/monochromatic input or `(comp_a, comp_b) == (False, False)`). Otherwise set `boxes = [box1]`. If `self.comp_c` is `True`, compute `p_def = deflate_conditional_posterior(posterior_2d, box1)`, evaluate `box2, j2_star, _, _ = select_renyi_foveal_subwindow(p_def)`, and if `j2_star > 1e-6` and `box2 != box1`, append `box2` to `boxes`. Return `(boxes, j1_star, posterior_2d)`.
