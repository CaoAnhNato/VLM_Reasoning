### 4.1 Adapter Chromatic Pre-Extraction & Nyquist-Gated Multi-Tile Slicing (`vintern_adapter.py`)
Given native RGB image $I$ of pixel size $(W, H)$ and cached unwarped `vit_embeds` (`[N_tiles, P_tile, D]`) with spatial tile grid $(g_{x,\text{glob}}, g_{y,\text{glob}})$ ($B = 1$ if $N_{\text{tiles}} == 1$ else $N_{\text{tiles}} - 1$; fallback $(g_{x,\text{glob}}, g_{y,\text{glob}}) = (B, 1)$ when $B \ne g_{x,\text{glob}} g_{y,\text{glob}}$; $p_{\text{side}} = \text{round}(\sqrt{P_{\text{tile}}})$, lattice shape $(H_g, W_g) = (p_{\text{side}} g_{y,\text{glob}}, \, p_{\text{side}} g_{x,\text{glob}})$):
1. **Unwarped Spatial Patch Lattice**: Reshape `vit_embeds[:B].detach()` (without mutating `self._cached_vit_embeds`) into `patch_embeds` $V \in \mathbb{R}^{H_g \times W_g \times D}$ where tile $b \in \{0, \dots, B-1\}$ maps to rows $[t_y p_{\text{side}}, (t_y + 1) p_{\text{side}})$ and columns $[t_x p_{\text{side}}, (t_x + 1) p_{\text{side}})$ with $t_y = \lfloor b / g_{x,\text{glob}} \rfloor$, $t_x = b \bmod g_{x,\text{glob}}$.
2. **Vectorial Native-RGB $SO(2)$ Color Structure Tensor (`duran2016collaborative` Def. 1, `lefkimmiatis2013hessian` Thm. 2)**: Let $I \in [0, 1]^{3 \times H \times W}$ be the `float32` 3-channel RGB tensor (`torch.from_numpy(rgb_arr).permute(2, 0, 1)`). Compute zero-padded forward finite differences across all 3 color channels **prior to channel reduction** (`F.pad` constant `0.0` mode):
   $$I_x = \begin{cases} \text{pad}(I[:, :, 1:] - I[:, :, :-1], \, (0, 1)) & \text{if } W > 1 \\ \mathbf{0}_{3 \times H \times W} & \text{if } W \le 1 \end{cases}, \qquad I_y = \begin{cases} \text{pad}(I[:, 1:, :] - I[:, :-1, :], \, (0, 0, 0, 1)) & \text{if } H > 1 \\ \mathbf{0}_{3 \times H \times W} & \text{if } H \le 1 \end{cases}$$
   Form collaborative channel-coupled second moments $g_{xx} = \frac{1}{3}\sum_{c=1}^{3} I_{x,c}^2$, $g_{yy} = \frac{1}{3}\sum_{c=1}^{3} I_{y,c}^2$, and $g_{xy} = \frac{1}{3}\sum_{c=1}^{3} I_{x,c} I_{y,c}$, pool $[g_{xx}, g_{yy}, g_{xy}] \in \mathbb{R}^{1 \times 3 \times H \times W}$ onto $(H_g, W_g)$ via `F.adaptive_avg_pool2d` to obtain $J_{xx}, J_{yy}, J_{xy} \in \mathbb{R}^{H_g \times W_g}$, and evaluate the 1-homogeneous $SO(2)$-invariant chromatic harmonic eigenvalue `optical_energy` on `vit_embeds.device` (`_extract_lattice_and_energy` retains its 4-tuple return `(patch_embeds, optical_energy, img_w, img_h)`):
   $$\mathcal{E}_{\text{CST}}(u) = \sqrt{\dfrac{\max\big(0.0, \; J_{xx}(u) J_{yy}(u) - J_{xy}(u)^2\big)}{\max\big(0.0, \; J_{xx}(u) + J_{yy}(u)\big) + 10^{-12}}} \in \mathbb{R}_{\ge 0}^{H_g \times W_g}$$
   *(Note: Any 1D straight color edge $\nabla I_c = a_c \mathbf{n}$ at angle $\theta \in [0, 2\pi)$ satisfies $J_{xx} J_{yy} - J_{xy}^2 = 0$, whereas 2D isoluminant colored stroke junctions satisfy $\det(J) > 0$.)*
3. **Prompt-Centered Layer-0 Query Embeddings**: Tokenize `question.strip()` (`add_special_tokens=False`) into $M$ token IDs. If $M == 0$ or `get_input_embeddings` is unavailable, set `query_embeds = None`; else look up `q_raw = embed_layer(q_ids).squeeze(0).float()` (`[M, D]`) and subtract the mean `float32` Layer-0 embedding of `PROMPT_INSTRUCTION` (`[1, D]`) to obtain `query_embeds` $E_Q \in \mathbb{R}^{M \times D}$.
4. **Single-Locus Unblurred Multi-Tile Framing & Nyquist Super-Resolution Gate (`encode_transient_roi_crops`, `extract_foveated_roi_crops`)**:
   - `extract_foveated_roi_crops` calls `box, j_star, _ = self.engine.foveate(optical_energy, patch_embeds, query_embeds=query_embeds)`. If `j_star <= 1e-6`, return `None`. Otherwise resolve $(_, \, g_{x,\text{glob}}, \, g_{y,\text{glob}}) = \text{self.\_resolve\_tile\_grid}(image, \, \text{int}(vit\_embeds.\text{shape}[0]))$, compute the global Nyquist magnification rate:
     $$M_{\text{glob}} = \min\!\left(\frac{\text{self.force\_image\_size} \cdot g_{x,\text{glob}}}{\max(1, W)}, \; \frac{\text{self.force\_image\_size} \cdot g_{y,\text{glob}}}{\max(1, H)}\right)$$
     map `box = (i1, j1, i2, j2)` to pixel coordinates `(round(j1 * W / W_g), round(i1 * H / H_g), round(j2 * W / W_g), round(i2 * H / H_g))`, and invoke `self.encode_transient_roi_crops(image, [(x1, y1, x2, y2)], max_tiles=3, min_magnification=M_glob)`.
   - Inside `encode_transient_roi_crops(self, image, bboxes, max_tiles=3, min_magnification=0.0)`: maintain `remaining = max_tiles` and `rgb_img = image.convert("RGB")` of size $(W, H)$. For each `bbox = (bx1, by1, bx2, by2)` in `bboxes` while `remaining > 0`:
     1. Canonicalize `cbx1, cbx2 = round(min(bx1, bx2)), round(max(bx1, bx2))` and `cby1, cby2 = round(min(by1, by2)), round(max(by1, by2))`, `raw_w = max(2, cbx2 - cbx1)`, `raw_h = max(2, cby2 - cby1)`, expand by `context_margin = 0.15` (`pad_x = round(0.15 * raw_w)`, `pad_y = max(round(0.15 * raw_h), 2)`), and clamp `[x1, x2] x [y1, y2]` into `[0, W] x [0, H]` (`min_dx = min(2, W)`, `min_dy = min(2, H)`, $\Delta_x = \max(\text{min\_dx}, x_2 - x_1)$, $\Delta_y = \max(\text{min\_dy}, y_2 - y_1)$).
     2. Select aspect-matched multi-tile grid $(g_x^*, g_y^*) = \text{DynamicMultiTileROICropper}(\text{target\_size}=\text{self.force\_image\_size}, \, \text{max\_tiles}=\text{remaining}, \, \text{min\_tile\_dim}=\max(1, \, \text{self.force\_image\_size} // 4)).\text{select\_grid}(\Delta_x, \Delta_y)$ (`hu2024docowl15`, `ye2023ureader`, `dehghani2023patch`), unlocking `(2, 1)` and `(3, 1)` multi-tile magnification up to `4.0x` on `< 4px` horizontal banners without `min_tile_dim = 224` blocking.
     3. Compute isotropic unit side $s_{\text{unit}} = \max(\Delta_x / g_x^*, \, \Delta_y / g_y^*)$, apply smooth patch-scale floor $s_{\text{min}} = \min(32.0, \min(W, H))$ with $s_{\text{floor}} = s_{\text{min}} + \frac{0.05 \min(W, H)}{1 + \exp(-0.05 (\max(\Delta_x, \Delta_y) - s_{\text{min}}))}$ and $s_{\text{unit}} \leftarrow \min\big(\max(s_{\text{unit}}, s_{\text{floor}}), \, W / g_x^*, \, H / g_y^*\big)$, and form enclosing in-bounds canvas dimensions $S_x = \min\big(W, \, \max(\Delta_x, \, s_{\text{unit}} g_x^*)\big)$ and $S_y = \min\big(H, \, \max(\Delta_y, \, s_{\text{unit}} g_y^*)\big)$.
     4. **Nyquist Super-Resolution Gate (`beyer2023flexivit` p. 4)**: Compute $M_{\text{crop}} = \min\big(\text{self.force\_image\_size} \cdot g_x^* / \max(1.0, S_x), \; \text{self.force\_image\_size} \cdot g_y^* / \max(1.0, S_y)\big)$. If `min_magnification > 0.0` and $M_{\text{crop}} \le \text{min\_magnification}$, skip this `bbox` (`continue`; if `crop_tiles` ends empty, return `None`).
     5. Otherwise center on $(\mu_x, \mu_y) = \big(0.5(x_1 + x_2), \, 0.5(y_1 + y_2)\big)$ and shift cleanly inside `[0, W] x [0, H]` (`sx1 = max(0.0, min(W - S_x, mu_x - 0.5 * S_x))`, `sy1 = max(0.0, min(H - S_y, mu_y - 0.5 * S_y))`), slicing `g_x^* * g_y^*` **100% unblurred** native-RGB sub-tiles (`0` `GaussianBlur`, `0` border reflection) resized via `BICUBIC` to `(self.force_image_size, self.force_image_size)`, and decrement `remaining -= g_x^* * g_y^*`. Encode stacked tiles in `bfloat16` via `self.model.extract_feature(pixel_values)` without mutating `self._cached_vit_embeds`.

### 4.2 Core Variational Foveation Equations (`src/nevfe/core/engine.py`)

- **(Eq. 1) 0-Homogeneous Rectified Bregman Root-Density Optical Distribution (`compute_bregman_optical_distribution`)**:
  Given `optical_energy` $\mathcal{E}_{\text{CST}} \in \mathbb{R}^{H_g \times W_g}$ (requiring `.dim() == 2`, signature `compute_bregman_optical_distribution(optical_energy: torch.Tensor, tau_v: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`), sanitize via `torch.nan_to_num(optical_energy.float(), nan=0.0, posinf=0.0, neginf=0.0)` and clamp $\mathcal{E}(u) = \max(0.0, \mathcal{E}_{\text{CST}}(u))$. If `e.numel() == 0`, return `e`. Let $u_0 = \frac{1.0}{\max(1, H_g W_g)}$ be the uniform distribution `unif` and $m_{\mathcal{E}} = \max_{v \in \Omega} \mathcal{E}(v)$.
  - *Boundary condition ($m_{\mathcal{E}} \le \epsilon$, or relative dynamic range $1.0 - \min_{v \in \Omega}(\mathcal{E}(v) / \max(m_{\mathcal{E}}, \epsilon)) \le \tau_v$)*: Return exact `unif` (guaranteeing exact uniform invariance on zero, monochromatic, and `float32`-ULP-perturbed constant grids across all scales up to `FLT_MAX`).
  - Otherwise, normalize to $\tilde{\mathcal{E}}(u) = \mathcal{E}(u) / \max(m_{\mathcal{E}}, \epsilon) \in [0.0, 1.0]$ (strictly 0-homogeneous: $P_{\text{opt}}(c\,\mathcal{E}) = P_{\text{opt}}(\mathcal{E})$ for all $c > 0$, preventing squaring overflow at `1e20..3.4e38`), subtract the unique spatial Bregman centroid $\bar{\mathcal{E}} = \text{mean}(\tilde{\mathcal{E}})$ (`banerjee2005bregman` Prop. 1), and form the rectified $L^2$ root-density distribution with `0.0%` background leakage:
    $$\psi_{\text{opt}}^{\text{raw}}(u) = \max\big(0.0, \; \tilde{\mathcal{E}}(u) - \bar{\mathcal{E}}\big), \qquad Z_{\text{opt}} = \sum_{v \in \Omega} \psi_{\text{opt}}^{\text{raw}}(v)^2, \qquad P_{\text{opt}}(u) = \begin{cases} \dfrac{\psi_{\text{opt}}^{\text{raw}}(u)^2}{\max(Z_{\text{opt}}, \, \epsilon)} & \text{if } Z_{\text{opt}} > \epsilon \\ u_0 & \text{otherwise} \end{cases}$$

- **(Eq. 2) Bregman-Centered Layer-0 Lexical Spatial Distribution (`compute_lexical_spatial_distribution`)**:
  Given `patch_embeds` $V \in \mathbb{R}^{H_g \times W_g \times D}$ (requiring `.dim() == 3`) and `query_embeds` $E_Q \in \mathbb{R}^{M \times D}$ (`Optional[torch.Tensor]`, `tau_v: float = 1e-6`), raise `ValueError` if $E_Q$ is a 2D tensor with $E_Q.\text{shape}[1] \ne D$.
  - *Boundary condition ($E_Q$ is `None`, `.dim() != 2`, $M == 0$, $D == 0$, or $H_g W_g == 0$)*: Return exact uniform distribution $P_{\text{lex}}(u) = \frac{1.0}{\max(1, H_g W_g)} \in \mathbb{R}^{H_g \times W_g}$.
  - Otherwise, sanitize both via `torch.nan_to_num(..., nan=0.0, posinf=0.0, neginf=0.0)` in `float32`, apply global peak scaling $\tilde{V} = V / \max(1.0, \max |V|) \in [-1.0, 1.0]$ and per-row peak scaling $\tilde{E}_{Q,m} = E_{Q,m} / \max(1.0, \max_d |E_{Q,m,d}|) \in [-1.0, 1.0]$ (so finite `1e20..3.4e38` rows never overflow `vector_norm` or suppress normal-scale tokens), subtract the spatial register/anisotropy centroid $\bar{V} = \frac{1}{H_g W_g}\sum_{v \in \Omega} \tilde{V}(v)$ (`darcet2024registers`, `mu2018allbutthetop`), compute $\Delta \tilde{V}(u) = \tilde{V}(u) - \bar{V}$ with Euclidean norms $r_V(u) = \|\Delta \tilde{V}(u)\|_2$ and $r_E(m) = \|\tilde{E}_{Q,m}\|_2$, apply dimension-scaled `float32` ULP gate $\tau_D = \tau_v \cdot (\text{float}(\max(1, D)))^{0.5}$ ($\hat{V}(u) = \Delta \tilde{V}(u) / \max(r_V(u), \tau_D)$ if $r_V(u) > \tau_D$ else $\mathbf{0}$, and $\hat{E}_m = \tilde{E}_{Q,m} / \max(r_E(m), \tau_v)$ if $r_E(m) > \tau_v$ else $\mathbf{0}$), evaluate peak cross-modal cosine alignment $c_Q(u) = \max_{1 \le m \le M} \langle \hat{V}(u), \hat{E}_m \rangle \in [-1, 1]$, compute $\Delta c_Q = c_Q - \text{mean}(c_Q)$ and $\sigma_Q = \sqrt{\max(0.0, \text{mean}(\Delta c_Q^2))}$, and map via canonical unit-variance Softmax:
    $$z_Q(u) = \begin{cases} \dfrac{\Delta c_Q(u)}{\max(\sigma_Q, \, \tau_v)} & \text{if } \sigma_Q > \tau_v \\ 0.0 & \text{if } \sigma_Q \le \tau_v \end{cases}, \qquad P_{\text{lex}}(u) = \text{Softmax}_{u \in \Omega}\big(z_Q(u)\big) \in \Delta^{H_g W_g - 1}$$

- **(Eq. 3) Riemannian Fisher-Rao Spherical Amplitude Geodesic Posterior (`compute_variational_posterior`)**:
  Given `p_opt`, `p_lex` $\in \mathbb{R}^{H_g \times W_g}$ (requiring matching 2D shapes), scalar `gamma_param` $\gamma \in [0.0, 1.0]$ (`Optional[float] = None`, defaulting via `AlgorithmConfig().gamma_param`), and ablation switches `(comp_a, comp_b)`, resolve $\gamma_{\text{eff}} = \text{clamp}(\gamma, 0.0, 1.0)$ if $\text{comp\_a} \wedge \text{comp\_b}$, $1.0$ if $\text{comp\_a} \wedge \neg\text{comp\_b}$, and $0.0$ if $\neg\text{comp\_a} \wedge \text{comp\_b}$.
  - *Boundary condition ($H_g W_g == 0$ or $\neg\text{comp\_a} \wedge \neg\text{comp\_b}$)*: Return uniform $P_\gamma^*(u) = \frac{1.0}{\max(1, H_g W_g)}$.
  - Otherwise, sanitize both inputs via `torch.nan_to_num(..., nan=0.0, posinf=0.0, neginf=0.0).clamp(min=0.0)`, peak-scale each by $\max(1.0, \max P)$, and simplex-normalize each onto $\Delta^{H_g W_g - 1}$ (falling back to `unif` if sum $\le \epsilon$). Evaluate the closed-form Riemannian Fisher-Rao ($\alpha = 0$) chordal barycenter on the positive Hilbert sphere $\mathcal{S}_+^{H_g W_g - 1}$ (`nielsen2011burbearao` Sec. II & IV):
    $$\psi_\gamma(u) = \gamma_{\text{eff}} \sqrt{\hat{P}_{\text{opt}}(u)} + (1.0 - \gamma_{\text{eff}}) \sqrt{\hat{P}_{\text{lex}}(u)}, \qquad Z_\gamma = \sum_{v \in \Omega} \psi_\gamma(v)^2, \qquad P_\gamma^*(u) = \begin{cases} \dfrac{\psi_\gamma(u)^2}{\max(Z_\gamma, \, \epsilon)} & \text{if } Z_\gamma > \epsilon \\ u_0 & \text{otherwise} \end{cases}$$
    *(Exact Partition Bound: $Z_\gamma = \gamma_{\text{eff}}^2 + (1 - \gamma_{\text{eff}})^2 + 2\gamma_{\text{eff}}(1 - \gamma_{\text{eff}})\,\text{BC}(\hat{P}_{\text{opt}}, \hat{P}_{\text{lex}}) \in [\gamma_{\text{eff}}^2 + (1 - \gamma_{\text{eff}})^2, \, 1.0]$, which is strictly $\ge 0.50$ at $\gamma_{\text{eff}} = 0.50$ even when $\hat{P}_{\text{opt}}$ and $\hat{P}_{\text{lex}}$ have disjoint supports, completely eliminating `-27.63 nat` `e`-geodesic cliffs while generating constructive $+2\gamma_{\text{eff}}(1-\gamma_{\text{eff}})\sqrt{\hat{P}_{\text{opt}}\hat{P}_{\text{lex}}}$ cross-modal interference.)*

- **(Eq. 4) Generalized Kullback–Leibler / Poisson-Bregman ($\beta = 1$) Subwindow Selection (`select_poisson_bregman_subwindow` & `NEVFEEngine.foveate`)**:
  Given `posterior_2d` $P \in \mathbb{R}^{H_g \times W_g}$ (requiring `.dim() == 2`, signature `select_poisson_bregman_subwindow(posterior_2d: torch.Tensor, comp_c: bool = True, eps_k: float = 1e-6, eps: float = 1e-12) -> Tuple[Tuple[int, int, int, int], float, float, float]`), sanitize via `torch.nan_to_num(posterior_2d.float(), nan=0.0, posinf=0.0, neginf=0.0).clamp(min=0.0)`.
  - *Boundary conditions*: If $H_g W_g == 0$, return `((0, 0, H_g, W_g), 0.0, 0.0, 0.0)`. Peak-scale $P$ by $\max(1.0, \max P)$ and normalize onto $\Delta^{H_g W_g - 1}$ (`unif` if sum $\le \epsilon$). If `not comp_c` or $H_g W_g \le 1$, return `((0, 0, H_g, W_g), 0.0, 1.0, 1.0)`.
  - Otherwise, form the zero-padded 2D summed-area table $S \in \mathbb{R}^{(H_g+1)\times(W_g+1)}$ and evaluate all nonempty axis-aligned subwindows $C = [i_1, i_2) \times [j_1, j_2)$ via `torch.triu_indices(..., offset=1)` with captured mass $p(C) \in [0.0, 1.0]$ and area fraction $a(C) = \frac{(i_2 - i_1)(j_2 - j_1)}{H_g W_g}$. Over the admissible zoom cone $\mathcal{C}_{\text{adm}} = \{C : p(C) > a(C) + \epsilon_k \;\wedge\; \epsilon_k \le a(C) \le 0.5\}$ ($\epsilon_k = 10^{-6}$), clamp $p_{\text{cl}} = \text{clamp}(p(C), \epsilon_k, 1.0)$ and $a_{\text{cl}} = \text{clamp}(a(C), \epsilon_k, 1.0)$, and evaluate the convex $\beta = 1$ Generalized Kullback–Leibler (Poisson-Bregman I-Divergence generated by $\phi(y) = y \ln y - y + 1$; `banerjee2005bregman` Table 1, `fevotte2011algorithms` Sec. 2.1):
    $$J_{\text{raw}}(C) = \text{nan\_to\_num}\!\left(p_{\text{cl}} \ln\!\frac{p_{\text{cl}}}{a_{\text{cl}}} - \big(p_{\text{cl}} - a_{\text{cl}}\big), \; \text{nan}=0.0, \, \text{posinf}=0.0, \, \text{neginf}=0.0\right), \qquad J_{\text{Pois}}(C) = \begin{cases} \max\big(0.0, \, J_{\text{raw}}(C)\big) & \text{if } C \in \mathcal{C}_{\text{adm}} \\ 0.0 & \text{otherwise} \end{cases}$$
    *(Anti-Inflation Property: For any background patch density $\rho_{\text{bg}} \le 1 < p/a$, $\frac{d J_{\text{Pois}}}{da} = \rho_{\text{bg}} \ln(p/a) - (p/a - 1) < 0$ identically, preventing whole-scene exterior-depletion inflation.)* Let $C^* = \arg\max_C J_{\text{Pois}}(C)$ and $J^* = J_{\text{Pois}}(C^*)$. If $J^* \le \epsilon_k$, return `((0, 0, H_g, W_g), 0.0, 1.0, 1.0)`; else return `((i_1^*, j_1^*, i_2^*, j_2^*), float(J^*), float(p(C^*)), float(a(C^*)))`.
  - Expose `NEVFEEngine.foveate(self, optical_energy, patch_embeds, query_embeds=None) -> Tuple[Tuple[int, int, int, int], float, torch.Tensor]`: execute `(Eq. 1) -> (Eq. 2) -> (Eq. 3) -> (Eq. 4)` with `(comp_a=self.comp_a, comp_b=self.comp_b, comp_c=self.comp_c)` and return `(box, j_star, posterior_2d)` (`0` secondary conditional deflation).
