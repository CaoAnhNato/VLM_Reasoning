Reshape `vit_embeds[:b].detach()` into `patch_embeds` $V \in \mathbb{R}^{H_g \times W_g \times D}$ ($H_g = P_{\text{side}} g_y$, $W_g = P_{\text{side}} g_x$) without mutating `self._cached_vit_embeds`, returning `(patch_embeds, W, H)` (retaining Action A pruning of dead RGB `P_opt` from `#114`).

3. **Multi-Locus Reservation & Anti-Keyhole Native-RGB Slicing (`encode_transient_roi_crops`, `extract_foveated_roi_crops`)**:
   - In `VinternNEVFEAdapter.__init__`, initialize `self._last_foveal_bboxes: List[List[int]] = []`.
   - In `extract_foveated_roi_crops(image, vit_embeds, question)`, reset `self._last_foveal_bboxes = []`, run `boxes, j_star, _ = self.engine.foveate(patch_embeds, query_embeds=query_embeds)`, and return `None` if `j_star <= 1e-6` or `not boxes`.      - Stop if `remaining <= 0`. Apply `15%` context padding (`pad_x = round(0.15 * raw_w)`, `pad_y = max(round(0.15 * raw_h), 2)`) clamped cleanly inside `[0, W] x [0, H]` (`dx >= min(2, W)`, `dy >= min(2, H)`).

     - **Anti-Keyhole Context Framing (`mathew2021docvqa`, `sidorov2020textcaps`)**: Set $s_{\min} = \min(\text{float}(\text{min\_tile\_dim}), \, \text{float}(\min(W, H)))$ (`112 px` on `448` ViT; `28 px` on `112` mock ViT), $s_{\text{floor}} = s_{\min} + \frac{0.05 \min(W, H)}{1.0 + \exp(-0.05(\max(dx, dy) - s_{\min}))}$, $s_{\text{unit}} = \min(\max(\max(dx / g_x^*, dy / g_y^*), s_{\text{floor}}), W / g_x^*, H / g_y^*)$, $S_x = \min(W, \max(dx, s_{\text{unit}} g_x^*))$, $S_y = \min(H, \max(dy, s_{\text{unit}} g_y^*))$.
     - Enforce Nyquist gate $M_{\text{crop}} = \min(\text{force\_image\_size} \cdot g_x^* / \max(1.0, S_x), \text{force\_image\_size} \cdot g_y^* / \max(1.0, S_y))$; if `min_magnification > 0.0` and $M_{\text{crop}} \le \text{min\_magnification}$, `continue`. Otherwise center on $(\mu_x, \mu_y) = (0.5(x_1 + x_2), 0.5(y_1 + y_2))$, shift inside `[0, W] x [0, H]`, slice `gx_star * gy_star` unblurred `BICUBIC` sub-tiles, and decrement `remaining -= gx_star * gy_star`.
   - In `NEVFEPipeline.run`, keep `stage1_bbox=[0, 0, w, h]` and include `"foveal_bboxes": list(getattr(self.adapter, "_last_foveal_bboxes", []))` inside `diagnostics`.

### 4.2 Unified `SPB-MLF` Core Operator (`src/nevfe/core/engine.py`)

- **Shared Spherical Patch Centering (`_normalize_patch_sphere`)**:
  For `patch_embeds` $V \in \mathbb{R}^{H_g \times W_g \times D}$ ($N = H_g W_g$), sanitize in `float32` via `torch.nan_to_num(patch_embeds.float(), nan=0.0, posinf=0.0, neginf=0.0).reshape(N, D)`, peak-scale $\tilde{V} = V_{\text{flat}} / \max(1.0, \max |V_{\text{flat}}|)$, subtract spatial mean $\bar{V} = \frac{1}{N}\sum_{u=1}^N \tilde{V}(u)$ (`darcet2024registers`, `mu2018allbutthetop`, `arandjelovic2018netvlad`), set $\tau_D = \tau_v \cdot (\text{float}(\max(1, D)))^{0.5}$, compute $r_V(u) = \|\tilde{V}(u) - \bar{V}\|_2$, and return $\hat{V}(u) = (\tilde{V}(u) - \bar{V}) / \max(r_V(u), \tau_D)$ if $r_V(u) > \tau_D$ else $\mathbf{0}_D$ along with scalar margin $\max_u r_V(u) - \tau_D$.

- **(Eq. 1) Per-Column Empirical-Standardized KL-Specificity Soft-`OR` Anchoring (`compute_spb_anchor_posterior`)**:
  Signature: `compute_spb_anchor_posterior(patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None, comp_a: bool = True, tau_v: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`.
  - Raise `ValueError` if `patch_embeds.dim() != 3` or if `query_embeds` is a 2D tensor with `query_embeds.shape[1] != D`.
  - *Boundary condition (`query_embeds is None`, `.dim() != 2`, $M == 0$, $D == 0$, $N \le 1$, or patch margin $\le 0.0$)*: Return exact uniform distribution `unif` $u_0 = \frac{1.0}{\max(1, N)} \in \mathbb{R}^{H_g \times W_g}$.
  - Otherwise sanitize `query_embeds` in `float32` via `torch.nan_to_num(query_embeds.float(), nan=0.0, posinf=0.0, neginf=0.0)`, row-peak-scale $\tilde{E}_{Q,m} = E_{Q,m} / \max(1.0, \max_d |E_{Q,m,d}|)$, unit-normalize $\hat{E}_m = \tilde{E}_{Q,m} / \max(\|\tilde{E}_{Q,m}\|_2, \tau_v)$ when $\|\tilde{E}_{Q,m}\|_2 > \tau_v$ else $\mathbf{0}_D$, and evaluate $S = \hat{V} \hat{E}_Q^\top \in [-1, 1]^{N \times M}$.
  - *Leave-One-Out branch (`not comp_a`)*: Exact `0f8a2d4d` / `iter_4` `011` unweighted max-pooled lexical alignment $c_Q = \max_{1 \le m \le M} S(\cdot, m)$, $\Delta c_Q = c_Q - \text{mean}(c_Q)$, $\sigma_c = \sqrt{\max(0.0, \text{mean}(\Delta c_Q^2))}$, returning `unif` if $\sigma_c \le \tau_v$ else $\text{Softmax}(\Delta c_Q / \max(\sigma_c, \tau_v)).\text{view}(H_g, W_g)$.
  - *Full specificity branch (`comp_a == True`; `ethayarajh2019contextual`, `nguyen2010estimating`, `arandjelovic2018netvlad`)*: Center each token column $\Delta S(u, m) = S(u, m) - \frac{1}{N}\sum_{u'=1}^N S(u', m)$ and compute per-column empirical spatial std $\sigma_m = \sqrt{\max(0.0, \text{mean}_u(\Delta S(\cdot, m)^2))}$ (returning `unif` if $\max_{1 \le m \le M} \sigma_m \le \tau_v$). Standardize every non-degenerate column ($\sigma_m > \tau_v$, scale-free per column with **zero** `1/D` floor and **zero** cross-column variance suppression of rare $K \ll N$ targets) to exact unit empirical spatial variance:
    $$Z_{\text{spec}}(u, m) = \begin{cases} \dfrac{\Delta S(u, m)}{\max(\sigma_m, \, \tau_v)} & \text{if } \sigma_m > \tau_v \\ 0.0 & \text{otherwise} \end{cases}, \qquad q_m = \text{Softmax}_{u \in \Omega}\big(Z_{\text{spec}}(\cdot, m)\big) \in \Delta^{N-1}$$
    *(Sparsity-Preserving De-Crowding Bound: Any $K_0$-patch repetitive background clone has $|Z_{\text{spec}}(\cdot, m_0)| \le \sqrt{(N-K_0)/K_0}$ [$\mathcal{I}_{m_0} \approx 0.61\text{ nats}$ at $K_0 = N/4$] and diffuse Gaussian noise stopwords yield $\mathcal{I}_{m_{\text{stop}}} \approx 0.45\text{ nats}$, whereas sparse `1x1`/`1x2` signboard targets [$K \ll N$] achieve $Z_{\text{spec}}(\cdot, m_1) = +\sqrt{(N-K)/K} \in [+8, +16]$ and $\mathcal{I}_{m_1} \in [3.5, 5.5]\text{ nats}$ even alongside broad clutter tokens.)* Compute each token's Spatial KL Information Gain above $u_0$:
    $$\mathcal{I}_m = \max\!\left(0.0, \; \sum_{u=1}^{N} \text{nan\_to\_num}\!\Big(q_m(u)\big(\ln\max(q_m(u), \epsilon) + \ln N\big), \; \text{nan}=0.0, \, \text{posinf}=0.0, \, \text{neginf}=0.0\Big)\right), \qquad w_m = \frac{\mathcal{I}_m^2}{\sum_{m'=1}^{M} \mathcal{I}_{m'}^2}$$
    (returning `unif` if $\sum_{m'} \mathcal{I}_{m'}^2 \le \epsilon$). Pool token potentials via the shift-stabilized disjunctive Soft-`OR` Log-Mixture envelope ($z_{\max}(u) = \max_m Z_{\text{spec}}(u, m)$):
    $$c_{\text{KL}}(u) = z_{\max}(u) + \ln\max\!\left(\epsilon, \; \sum_{m=1}^{M} w_m \exp\!\big(Z_{\text{spec}}(u, m) - z_{\max}(u)\big)\right)$$
    Center $\Delta c_{\text{KL}} = c_{\text{KL}} - \text{mean}(c_{\text{KL}})$, compute $\sigma_{\text{KL}} = \sqrt{\max(0.0, \text{mean}(\Delta c_{\text{KL}}^2))}$ (returning `unif` if $\sigma_{\text{KL}} \le \tau_v$), and return $P_{\text{anchor}} = \text{Softmax}(\Delta c_{\text{KL}} / \max(\sigma_{\text{KL}}, \tau_v)).\text{view}(H_g, W_g) \in \Delta^{N-1}$.

- **(Eq. 2) Anisotropic Coifman–Lafon Horizontal-Signboard Markov Resolvent (`compute_signboard_manifold_posterior`)**:
  Signature: `compute_signboard_manifold_posterior(p_anchor: torch.Tensor, patch_embeds: torch.Tensor, gamma_param: Optional[float] = None, comp_b: bool = True, tau_v: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`.
  - Raise `ValueError` unless `p_anchor.dim() == 2`, `patch_embeds.dim() == 3`, and `p_anchor.shape == patch_embeds.shape[:2]`. If $N == 0$, return `torch.zeros_like(p_anchor, dtype=torch.float32)`.
  - Sanitize `p_anchor` in `float32`, peak-scale by $\max(1.0, \max P_{\text{anchor}})$, and normalize onto $\Delta^{N-1}$ (`unif` if sum $\le \epsilon$) to obtain $\hat{P}_{\text{anchor}} \in \Delta^{N-1}$. Resolve $\gamma_{\text{eff}} = \text{clamp}(\gamma, 0.0, 1.0)$ if `comp_b` else $0.0$ (defaulting $\gamma$ via `AlgorithmConfig().gamma_param` when `None`). If $\gamma_{\text{eff}} \le \epsilon$, $N \le 1$, $D == 0$, $\max_u \hat{P}_{\text{anchor}}(u) - \min_u \hat{P}_{\text{anchor}}(u) \le \tau_v$ (uniform-anchor fixed-point passthrough so `query_embeds=None`/empty/all-`NaN` abstains cleanly with $J_1^* = 0.0$), or patch margin $\le 0.0$, return $\hat{P}_{\text{anchor}}.\text{view}(H_g, W_g)$.
  - Over the horizontal reading-line gap-bridging stencil $\mathcal{N}_{\text{line}}(u, v) = 1.0$ if $|i_u - i_v| == 0 \wedge 1 \le |j_u - j_v| \le 2$, $0.5$ if $|i_u - i_v| == 1 \wedge |j_u - j_v| \le 1$, else $0.0$, form unit-chord conductance $W_{uv} = \max(0.0, \langle \hat{V}(u), \hat{V}(v) \rangle - 0.5)^2 \cdot \mathcal{N}_{\text{line}}(u, v)$ (`caron2021dino`, `vonluxburg2007spectral`), Coifman–Lafon density-normalized conductance $\widetilde{W}_{uv} = \frac{W_{uv}}{\max(d_u^{\text{raw}} d_v^{\text{raw}}, \epsilon)}$ when $d_u^{\text{raw}}, d_v^{\text{raw}} > \epsilon$ else $0.0$ (`hein2007graph` p. 2), and row-stochastic Markov kernel $K_{uv} = \widetilde{W}_{uv} / \max(d_u, \epsilon)$ if $d_u > \epsilon$ else $\delta_{uv}$ (preserving exact $0.0$ peak dilution on isolated `1 x 1` `CLASS_A` glyphs). At exact Brownian signboard horizon $r_N = \frac{1.0}{N}$ (`gleich2015pagerank`, `nadler2006diffusion`; characteristic 1D diffusion span $\sqrt{N} \approx W_g$), solve the strictly column-diagonally-dominant nonsingular M-matrix system via `torch.linalg.solve`:
    $$\Big(I_N - (1.0 - r_N) K^\top\Big) P_{\text{line}} = r_N \hat{P}_{\text{anchor}}, \qquad P_\gamma^* = \frac{(1.0 - \gamma_{\text{eff}})\hat{P}_{\text{anchor}} + \gamma_{\text{eff}}\hat{P}_{\text{line}}}{\big\|(1.0 - \gamma_{\text{eff}})\hat{P}_{\text{anchor}} + \gamma_{\text{eff}}\hat{P}_{\text{line}}\big\|_1} \in \Delta^{N-1}$$
    (sanitizing $P_{\text{line}}$ onto $\Delta^{N-1}$ with fallback to $\hat{P}_{\text{anchor}}$).

- **(Eq. 3) Submodular Conditional-Exterior 2-Locus Poisson-Bregman Selection (`select_submodular_bregman_loci` & `NEVFEEngine.foveate`)**:
  Signature: `select_submodular_bregman_loci(posterior_2d: torch.Tensor, comp_c: bool = True, eps_k: float = 1e-6, eps: float = 1e-12) -> List[Tuple[Tuple[int, int, int, int], float, float, float]]`.
  - Raise `ValueError` if `posterior_2d.dim() != 2`. If $N == 0$, return `[((0, 0, H_g, W_g), 0.0, 0.0, 0.0)]`. Sanitize `posterior_2d` in `float32`, peak-scale by $\max(1.0, \max P)$, and normalize onto $\Delta^{N-1}$ (`unif` if sum $\le \epsilon$). If `not comp_c` or $N \le 1$, return `[((0, 0, H_g, W_g), 0.0, 1.0, 1.0)]`.
  - **Primary Locus $C_1^*$ (`banerjee2005bregman`, `fevotte2011algorithms`)**: Using 2D summed-area table `sat = F.pad(p, (1, 0, 1, 0)).cumsum(dim=0).cumsum(dim=1)` and `torch.triu_indices(..., offset=1)`, evaluate all axis-aligned subwindows $C = [i_1, i_2) \times [j_1, j_2)$ with mass $p(C) \in [0, 1]$ and area fraction $a(C) = \frac{(i_2 - i_1)(j_2 - j_1)}{N}$. Over $\mathcal{C}_{\text{adm}}^{(1)} = \{C : p(C) > a(C) + \epsilon_k \;\wedge\; \epsilon_k \le a(C) \le 0.5\}$, maximize $J_{\text{Pois}}(P, C) = \max\big(0.0, \, p_{\text{cl}}\ln(p_{\text{cl}}/a_{\text{cl}}) - (p_{\text{cl}} - a_{\text{cl}})\big)$. If $J_1^* \le \epsilon_k$, return `[((0, 0, H_g, W_g), 0.0, 1.0, 1.0)]`. Otherwise unpack `bi1, bj1, bi2, bj2 = b1` and record `loci = [(b1, j1_star, p1, a1)]`.
  - **Complementary Disjoint Locus $C_2^*$ (`krause2008near` p. 2, `walther2010optimal` p. 7, `nguyen2010estimating` p. 2)**: Let $m_{\text{rem}} = 1.0 - p_1$ and $a_{\text{rem}} = 1.0 - a_1$. When $m_{\text{rem}} > \epsilon_k$ and $a_{\text{rem}} > \epsilon_k$, restrict to strictly spatially disjoint subwindows $C \cap C_1^* = \emptyset$ (`(i2 <= bi1) | (i1 >= bi2)` or `(j2 <= bj1) | (j1 >= bj2)`) satisfying unconditional 1-bit spatial enrichment $p(C) > 2.0\,a(C) + \epsilon_k$, joint majority coverage $p_1 + p(C) > 0.5$, and $\epsilon_k \le a(C) \le 0.5\,a_{\text{rem}}$. Evaluate the conditional-exterior Poisson-Bregman divergence $J_{\text{Pois}}(\tilde{P}_{\text{ext}}, C)$ on $\tilde{p} = \text{clamp}(p(C)/m_{\text{rem}}, \epsilon_k, 1.0)$ vs $\tilde{a} = \text{clamp}(a(C)/a_{\text{rem}}, \epsilon_k, 1.0)$, and append `(b2, j2_ext, p2, a2)` to `loci` iff $J_2^{\text{ext}*} \ge 0.5\,J_1^*$ and $J_2^{\text{ext}*} > \epsilon_k$.
  - Expose `NEVFEEngine.foveate(self, patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None) -> Tuple[List[Tuple[int, int, int, int]], float, torch.Tensor]`: execute `(Eq. 1) -> (Eq. 2) -> (Eq. 3)` with `(comp_a=self.comp_a, comp_b=self.comp_b, comp_c=self.comp_c)`, unpack `_, j1, _, _ = loci[0]`, and return `([loc[0] for loc in loci] if j1 > 1e-6 else [(0, 0, H_g, W_g)], j1, p_post)`.

### 4.3 Retained Baseline Single-Step `IG-VFED` Equations (`t = 1` vs. `t > 1` & Decoupled Stage-A Ablation)
- **(Eq. 4) Mean-Field Visual Reference (`compute_mean_field_reference_embeddings`)**: $V^0 = \mathbf{1}\bar{\boldsymbol{v}}^\top$ over `dim=(0, 1)` (3D) or `dim=0` (2D).
- **(Eq. 5) Bhattacharyya Coefficient & Geodesic Coupling (`compute_bhattacharyya_coefficient`, `compute_dynamic_coupling`)**: $\text{BC}_t = \text{clamp}(\sum_{w=1}^V \sqrt{\max(0.0, p_{t,w}^+ p_{t,w}^0)}, 0.0, 1.0)$; $\alpha_t = \lambda$ if $\neg d_a$ else $\lambda\sqrt{\text{clamp}(1.0 - \text{BC}_t^2, 0.0, 1.0)} + \mathbb{I}[t == 1 \wedge d_c]\,\lambda\,\text{BC}_t$.
