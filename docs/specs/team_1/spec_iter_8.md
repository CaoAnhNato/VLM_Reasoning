### 4.2 Core `EBW-MSF` Equations (`src/nevfe/core/engine.py`)

- **(Eq. 1) Diffusion-Free KL-Specificity Soft-`OR` Spatial Anchor (`compute_optical_anchor_posterior`)**:
  Signature: `compute_optical_anchor_posterior(patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None, comp_a: bool = True, tau_v: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`.

  - *Boundary conditions*: If `query_embeds is None` or `query_embeds.dim() != 2`, return $u_0$. If `query_embeds.shape[1] != dim`, raise `ValueError`. If `query_embeds.shape[0] == 0` or `dim == 0` or $N \le 1$, return $u_0$.
  - Sanitize $V_{\text{raw}} = \text{nan\_to\_num}(patch\_embeds.\text{float}(), \, 0.0, 0.0, 0.0).\text{view}(N, D)$ and $Q_{\text{raw}} = \text{nan\_to\_num}(query\_embeds.\text{float}(), \, 0.0, 0.0, 0.0)$. Peak-scale and center spatial anisotropy $\Delta\tilde{V} = \tilde{V} - \frac{1}{N}\sum_{u=1}^{N} \tilde{V}_u$ where $\tilde{V} = V_{\text{raw}} / \max(1.0, \max |V_{\text{raw}}|)$, and peak-scale each query row $\tilde{Q}_m = Q_{\text{raw},m} / \max(1.0, \max_d |Q_{\text{raw},m,d}|)$. Compute $r_V(u) = \|\Delta\tilde{V}_u\|_2$, $\tau_D = \tau_v \sqrt{\text{float}(\max(1, D))}$ (if $\max_u r_V(u) \le \tau_D$, return $u_0$), $r_E(m) = \|\tilde{Q}_m\|_2$, unit vectors $\hat{V}_u = \Delta\tilde{V}_u / \max(r_V(u), \tau_D)$ if $r_V(u) > \tau_D$ else $\mathbf{0}$ and $\hat{E}_m = \tilde{Q}_m / \max(r_E(m), \tau_v)$ if $r_E(m) > \tau_v$ else $\mathbf{0}$, and cross-modal cosine matrix $S = \hat{V} \hat{E}^\top \in [-1, 1]^{N \times M}$.
  - *Champion `0f8a2d4d` Fallback (`not comp_a`)*: Compute $c(u) = \max_{1 \le m \le M} S_{u,m}$, $\Delta c = c - \text{mean}(c)$, $\sigma_c = \sqrt{\max(0.0, \text{mean}(\Delta c^2))}$, and return $\text{Softmax}(\Delta c / \max(\sigma_c, \tau_v)).\text{view}(h_g, w_g)$ if $\sigma_c > \tau_v$ else $u_0$.
  - *KL-Specificity Soft-`OR` (`comp_a == True`; `minderer2022owlvit`, `radenovic2019finetuning`)*: Standardize each query token's spatial response across patches: $\Delta S_{u,m} = S_{u,m} - \frac{1}{N}\sum_{v=1}^{N} S_{v,m}$, $\sigma_m = \sqrt{\max(0.0, \frac{1}{N}\sum_{v=1}^{N} \Delta S_{v,m}^2)}$. If $\max_m \sigma_m \le \tau_v$, return $u_0$. Set $Z_{u,m} = \Delta S_{u,m} / \max(\sigma_m, \tau_v)$ if $\sigma_m > \tau_v$ else $0.0$, evaluate per-token spatial posterior $q_{u,m} = \text{Softmax}_{u}(Z_{u,m})$ and empirical spatial KL specificity $I_m = \max\!\big(0.0, \, \sum_{u=1}^{N} \text{nan\_to\_num}(q_{u,m}(\ln \max(q_{u,m}, \epsilon) + \ln N), \, 0.0, 0.0, 0.0)\big)$, form squared-KL weights $w_m = I_m^2 / \max(\sum_{k=1}^{M} I_k^2, \, \epsilon)$ (returning $u_0$ if $\sum_k I_k^2 \le \epsilon$), aggregate via shift-stabilized log-sum-exp Soft-`OR`:
    $$c_{\text{KL}}(u) = z_{\max}(u) + \ln \max\!\left(\epsilon, \; \sum_{m=1}^{M} w_m \exp\!\big(Z_{u,m} - z_{\max}(u)\big)\right), \qquad z_{\max}(u) = \max_{1 \le m \le M} Z_{u,m}$$
    and return $\text{Softmax}(\Delta c_{\text{KL}} / \max(\sigma_{\text{KL}}, \tau_v)).\text{view}(h_g, w_g)$ if $\sigma_{\text{KL}} > \tau_v$ else $u_0$, where $\Delta c_{\text{KL}} = c_{\text{KL}} - \text{mean}(c_{\text{KL}})$ and $\sigma_{\text{KL}} = \sqrt{\max(0.0, \text{mean}(\Delta c_{\text{KL}}^2))}$.

- **(Eq. 2) Single-Locus Diffusion-Free Poisson-Bregman Subwindow Selection (`select_optical_foveal_locus` & `NEVFEEngine.foveate`)**:
  Signature: `select_optical_foveal_locus(posterior_2d: torch.Tensor, eps_k: float = 1e-6, eps: float = 1e-12) -> Tuple[Tuple[int, int, int, int], float, float, float]`.

Peak-scale $P \leftarrow P / \max(1.0, \max P)$, normalize onto $\Delta^{N-1}$ (uniform $1/N$ if sum $\le \epsilon$), and if $N \le 1$, return `((0, 0, h_g, w_g), 0.0, 1.0, 1.0)`.
  - Form 2D summed-area table $S \in \mathbb{R}^{(h_g+1)\times(w_g+1)}$ (`F.pad(p, (1, 0, 1, 0)).cumsum(0).cumsum(1)`) and evaluate all axis-aligned subwindows $B = [i_1, i_2) \times [j_1, j_2)$ via `torch.triu_indices(..., offset=1)` with mass $p(B) \in [0, 1]$ and area fraction $a(B) = \frac{(i_2 - i_1)(j_2 - j_1)}{N}$. Over $\mathcal{B} = \{B : p(B) > a(B) + \epsilon_k \;\wedge\; \epsilon_k \le a(B) \le 0.5\}$, maximize $J(B) = p_{\text{cl}} \ln(p_{\text{cl}} / a_{\text{cl}}) - (p_{\text{cl}} - a_{\text{cl}})$ ($p_{\text{cl}} = \text{clamp}(p(B), \epsilon_k, 1.0)$, $a_{\text{cl}} = \text{clamp}(a(B), \epsilon_k, 1.0)$). If $J^* \le \epsilon_k$, return `((0, 0, h_g, w_g), 0.0, 1.0, 1.0)`; else return `(box_star, j_star, mass_star, area_star)`.
  - `NEVFEEngine.foveate(self, patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None) -> Tuple[Tuple[int, int, int, int], float, torch.Tensor]` runs `(Eq. 1)` with `comp_a=self.comp_a` followed by `(Eq. 2)` and returns `(box, j_star, p_post)`.

- **(Eq. 3) Exact `1:1` Square-Isotropic `25%`-Overlapped Complete-Word Multi-Strip Planner (`plan_isotropic_strip_boxes`)**:
  Signature: `plan_isotropic_strip_boxes(bbox: Tuple[int, int, int, int], img_size: Tuple[int, int], patch_stride: float, max_tiles: int = 2 + 1, comp_b: bool = True, eps: float = 1e-6) -> Tuple[List[Tuple[int, int, int, int]], Tuple[int, int], float]`.
  - Given `img_size = (W, H)`, return `[], (1, 1), 0.0` if $W \le 0$, $H \le 0$, or `max_tiles <= 0`. Clamp `bbox` inside `[0, W] x [0, H]` with spans $\Delta_x = \max(\min(2.0, W), \, \min(W, cx_2 - cx_1))$, $\Delta_y = \max(\min(2.0, H), \, \min(H, cy_2 - cy_1))$, and $s_p = \max(1.0, \text{float}(patch\_stride))$.
  - Set sub-tile stride factor $\sigma_{\text{step}} = 1.0 - 0.5 \cdot 0.5 = 0.75$ (`25%` seam overlap; `zhang2019making`, `dong2016srcnn`) if `comp_b` else $1.0$ (`0%` seam overlap), and complete-word per-sub-tile minimum span $d_{\min} = 2.0\,s_p$ (`56 px`; `wang2020textzoom`) if `comp_b` else $(2.0 + 2.0)\,s_p$ (`112 px`, matching `0f8a2d4d`'s `min_tile_dim`).
  - Candidate grids: $\mathcal{G} = \{(1, 1)\} \cup (\{(2, 1), (1, 2)\} \text{ if } \text{max\_tiles} \ge 2) \cup (\{(2 + 1, 1), (1, 2 + 1)\} \text{ if } \text{max\_tiles} \ge 2 + 1) \cup (\{(2, 2)\} \text{ if } \text{max\_tiles} \ge 2 + 2)$.
  - *Unified Admissibility*: With $f_x(g_x) = 1.0 + \sigma_{\text{step}}(g_x - 1)$ and $f_y(g_y) = 1.0 + \sigma_{\text{step}}(g_y - 1)$, $(g_x, g_y) \in \mathcal{G}_{\text{adm}}$ iff $(g_x == 1 \vee \Delta_x \ge f_x(g_x)\,d_{\min}) \wedge (g_y == 1 \vee \Delta_y \ge f_y(g_y)\,d_{\min}) \wedge f_x(g_x)\,s_p \le W + \epsilon \wedge f_y(g_y)\,s_p \le H + \epsilon$ (fallback $\mathcal{G}_{\text{adm}} \leftarrow \{(1, 1)\}$ if empty).
  - Select $(g_x^*, g_y^*) = \arg\min_{(g_x, g_y) \in \mathcal{G}_{\text{adm}}} \big(|\ln(\max(\epsilon, \Delta_x) / \max(\epsilon, \Delta_y)) - \ln(f_x(g_x) / f_y(g_y))|, \; g_x g_y\big)$.
  - *Unconditional `56px` Floor & Exact Integer Square Sub-Tiles (`shi2017crnn`)*: With $f_x = f_x(g_x^*)$, $f_y = f_y(g_y^*)$, and **unconditional** floor $s_{\text{fl}} = \min(2.0\,s_p, \min(W, H))$ (shared across both `comp_b=True` and `comp_b=False`), compute continuous isotropic side $s_{\text{unit}} = \min\!\big(\max(\Delta_x / f_x, \, \Delta_y / f_y, \, s_{\text{fl}}), \; W / f_x, \; H / f_y\big)$, exact integer square sub-tile side $s_{\text{int}} = \max(1, \min(W, H, \text{int}(\text{round}(s_{\text{unit}}))))$, enclosing strip dimensions $S_x = \min(W, \max(\text{float}(s_{\text{int}}), s_{\text{unit}} f_x))$, $S_y = \min(H, \max(\text{float}(s_{\text{int}}), s_{\text{unit}} f_y))$, in-bounds origin $sx_1 = \max(0.0, \min(W - S_x, 0.5(cx_1 + cx_2 - S_x)))$, $sy_1 = \max(0.0, \min(H - S_y, 0.5(cy_1 + cy_2 - S_y)))$, and step $(\delta_x, \delta_y) = \big((S_x - s_{\text{int}}) / \max(1, g_x^* - 1) \text{ if } g_x^* > 1 \text{ else } 0.0, \; (S_y - s_{\text{int}}) / \max(1, g_y^* - 1) \text{ if } g_y^* > 1 \text{ else } 0.0\big)$. For $t_y \in \{0, \dots, g_y^* - 1\}, t_x \in \{0, \dots, g_x^* - 1\}$, compute $bx_1 = \max(0, \min(W - s_{\text{int}}, \text{int}(\text{round}(sx_1 + t_x \delta_x))))$, $by_1 = \max(0, \min(H - s_{\text{int}}, \text{int}(\text{round}(sy_1 + t_y \delta_y))))$, append exact square box `(bx_1, by_1, bx_1 + s_int, by_1 + s_int)`, and return `(boxes, (gx_s, gy_s), float(s_int))`.

- **(Eq. 4) Character-Scale $7\times 7$ Extremum-Bounded MMSE Local-Wiener Stroke Restoration (`_binomial_smooth_2d` & `restore_extremum_wiener_strokes`)**:
  Signature: `restore_extremum_wiener_strokes(rgb_chw: torch.Tensor, magnification: float = 2.0, gamma_param: Optional[float] = None, comp_c: bool = True, eps: float = 1e-12) -> torch.Tensor`.
  - Require `rgb_chw.dim() == 2 + 1` (`[C, H_t, W_t]`, else raise `ValueError`). Sanitize $I = \text{nan\_to\_num}(rgb\_chw.\text{float}(), \, \text{nan}=0.0, \text{posinf}=1.0, \text{neginf}=0.0).\text{clamp}(0.0, 1.0)$ with `(c_t, h_t, w_t) = I.shape`.
  - Resolve $\gamma_{\text{eff}} = \text{clamp}(\gamma, 0.0, 1.0)$ if `comp_c` else $0.0$ ($\gamma$ defaulting to `AlgorithmConfig().gamma_param` when `None`), $M_{\text{eff}} = \max(1.0, \text{float}(magnification))$, and bicubic interpolation footprint scale $\eta(M_{\text{eff}}) = 1.0 - 1.0 / M_{\text{eff}}^2 \in [0.0, 1.0)$.
  - *Boundary condition ($c_t == 0$, $h_t w_t \le 1$, or $\gamma_{\text{eff}}\,\eta(M_{\text{eff}}) \le \epsilon$)*: Return $I$ identically (`0.0` ULP perturbation when `comp_c == False`, $\gamma == 0.0$, $M_{\text{eff}} \le 1.0$, or $1\times 1$ / $0$-channel input; `chan2017plug` Bounded Denoiser asymptotic identity).
  - Define $\mathcal{G}(X)$ as two passes of separable symmetric `[1, 2, 1] / 4` (`0.5 * 0.5`) reflection-padded 2D binomial smoothing (`zhang2019making`, `romano2017little`): along width when $w_t > 1$ using `cat([out[:, :, 1:2], out, out[:, :, w_t - 2 : w_t - 1]], dim=-1)`, and along height when $h_t > 1$ using `cat([out[:, 1:2, :], out, out[:, h_t - 2 : h_t - 1, :]], dim=1)`.
  - Extract achromatic luminance $L = \frac{1}{c_t}\sum_{c=1}^{c_t} I_c \in [0, 1]^{1 \times H_t \times W_t}$, zero-phase RED Laplacian stroke detail $d = L - \mathcal{G}(L)$ (`romano2017little`), local detail energy $v_{\text{loc}} = \mathcal{G}(d^2) \ge 0$, stationary background noise floor $\nu_0 = \text{median}(v_{\text{loc}}) \ge 0$ (`zhang2017dncnn`, `zhang2021plug`), and MMSE local-Wiener shrinkage gain:
    $$g_W(y, x) = \frac{\max\!\big(0.0, \; v_{\text{loc}}(y, x) - 2.0\,\nu_0\big)}{v_{\text{loc}}(y, x) + 2.0\,\nu_0 + \epsilon} \in [0.0, 1.0)$$
  - Compute the character-scale $7\times 7$ (`r_ext = 2 + 1`, `k_ext = 2 * (2 + 1) + 1`) replicate-padded per-channel discrete extremum envelope (`chan2017plug` p. 3; `ulyanov2020dip` p. 6):
    $$P_{\text{rep}} = \text{pad}_{\text{replicate}}\!\big(I.\text{unsqueeze}(0), \; (r_{\text{ext}}, r_{\text{ext}}, r_{\text{ext}}, r_{\text{ext}})\big), \quad I_{\max} = \text{max\_pool2d}(P_{\text{rep}}, k_{\text{ext}}, 1).\text{squeeze}(0), \quad I_{\min} = -\text{max\_pool2d}(-P_{\text{rep}}, k_{\text{ext}}, 1).\text{squeeze}(0)$$
    and project the unconstrained MMSE Wiener update $\hat{I}_c = I_c + 2.0\,\gamma_{\text{eff}}\,\eta(M_{\text{eff}})\,g_W\,d$ onto $[I_{\min}, I_{\max}] \cap [0.0, 1.0]$:
    $$\tilde{I}_c(y, x) = \text{clamp}\!\Big(\min\!\big(\max(\hat{I}_c(y, x), \; I_{\min}(c, y, x)), \; I_{\max}(c, y, x)\big), \; 0.0, \; 1.0\Big)$$

### 4.3 Retained Baseline Single-Step `IG-VFED` Equations (`t = 1` vs. `t > 1` & Decoupled Stage-A Ablation)

For standalone `NEVFEEngine.decode_step` (preserving `test_01..test_15` backward compatibility): if $\neg d_a$, $\alpha_t = \lambda$; else $\alpha_t = \lambda \sqrt{\text{clamp}(1.0 - \text{BC}_t^2, 0.0, 1.0)} + \mathbb{I}[t == 1 \wedge d_c] \, \lambda \, \text{BC}_t$.
