Compute $r_V(u) = \|\Delta\tilde{V}_u\|_2$, $r_E(m) = \|\tilde{Q}_m\|_2$, and $\tau_D = \tau_v \sqrt{\text{float}(\max(1, D))}$; if $\max_u r_V(u) \le \tau_D$ or $\max_m r_E(m) \le \tau_v$, return $u_0$. Normalize $\hat{V}_u = \Delta\tilde{V}_u / \max(r_V(u), \tau_D)$ if $r_V(u) > \tau_D$ else $\mathbf{0}$ and $\hat{E}_m = \tilde{Q}_m / \max(r_E(m), \tau_v)$ if $r_E(m) > \tau_v$ else $\mathbf{0}$, and compute cross-modal cosine alignment $S = \hat{V}\hat{E}^\top \in [-1, 1]^{N \times M}$ (`zhou2022extract` p. 7).
  - *Lexical Aggregation (`comp_b == False` vs. `comp_b == True`)*:
    - If `not comp_b` (`0f8a2d4d` unweighted `max_m` fallback): $c_{\text{raw}}(u) = \max_{1 \le m \le M} S_{u,m}$.
    - If `comp_b == True` (Shared-RMS Stroke-Aligned KL-Specificity Soft-`OR`; `minderer2022owlvit` p. 5, `radenovic2019finetuning` p. 5, `hu2020senet` p. 3): Mean-center each token column $\Delta S_{u,m} = S_{u,m} - \frac{1}{N}\sum_{v=1}^{N} S_{v,m}$ and standardize across the entire matrix by the **single shared RMS scale** $\sigma_S = \sqrt{\max\!\big(0.0, \, \frac{1}{NM}\sum_{u=1}^{N}\sum_{m=1}^{M} \Delta S_{u,m}^2\big)}$ (returning $u_0$ if $\sigma_S \le \tau_v$; preserving true cosine contrast amplitude across tokens without inflating `1–4`-patch face blips):
      $$Z_{u,m} = \frac{\Delta S_{u,m}}{\max(\sigma_S, \, \tau_v)}, \qquad q_{u,m} = \text{Softmax}_u(Z_{u,m}), \qquad I_m = \max\!\left(0.0, \; \sum_{u=1}^{N} \text{nan\_to\_num}\!\big(q_{u,m}(\ln \max(q_{u,m}, \epsilon) + \ln N), \, 0.0, 0.0, 0.0\big)\right)$$
      Compute stroke-aligned query specificity $s_m = \big(\sum_{u=1}^{N} \pi_u q_{u,m}\big)\,I_m$, normalized squared weights $w_m = s_m^2 / \max(\sum_{k=1}^{M} s_k^2, \, \epsilon)$ (returning $u_0$ if $\sum_k s_k^2 \le \epsilon$), and shift-stabilized log-sum-exp Soft-`OR`:
      $$c_{\text{raw}}(u) = z_{\max}(u) + \ln \max\!\left(\epsilon, \; \sum_{m=1}^{M} w_m \exp\!\big(Z_{u,m} - z_{\max}(u)\big)\right), \qquad z_{\max}(u) = \max_{1 \le m \le M} Z_{u,m}$$
  - *Multiplicative Log-Linear Spatial Bayes Update*: Standardize $\Delta c = c_{\text{raw}} - \text{mean}(c_{\text{raw}})$, $\sigma_c = \sqrt{\max(0.0, \text{mean}(\Delta c^2))}$ (returning $u_0$ if $\sigma_c \le \tau_v$), form $p_{\text{lex}} = \text{Softmax}(\Delta c / \max(\sigma_c, \tau_v))$, and return normalized Bayesian posterior $p^*(u) = \frac{\pi_u \, p_{\text{lex}}(u)}{\max(\epsilon, \sum_{v=1}^{N} \pi_v \, p_{\text{lex}}(v))}$ reshaped to `(h_g, w_g)` (or $u_0$ if $\sum_v \pi_v p_{\text{lex}}(v) \le \epsilon$).

- **(Eq. 3) Single-Locus Generalized KL / Poisson–Bregman Subwindow Selection (`select_optical_foveal_locus` & `NEVFEEngine.foveate`)**:
  Signature: `select_optical_foveal_locus(posterior_2d: torch.Tensor, eps_k: float = 1e-6, eps: float = 1e-12) -> Tuple[Tuple[int, int, int, int], float, float, float]`.
  - Require `posterior_2d.dim() == 2` (else raise `ValueError`); let `(h_g, w_g) = posterior_2d.shape`, $N = h_g w_g$. Sanitize $P = \text{nan\_to\_num}(posterior\_2d.\text{float}(), \, 0.0, 0.0, 0.0).\text{clamp}(\min=0.0)$. If $N == 0$, return `((0, 0, h_g, w_g), 0.0, 0.0, 0.0)`. Peak-scale $P \leftarrow P / \max(1.0, \max P)$, normalize onto $\Delta^{N-1}$ (uniform $1/N$ if sum $\le \epsilon$), and if $N \le 1$, return `((0, 0, h_g, w_g), 0.0, 1.0, 1.0)`.
  - Form 2D summed-area table $S \in \mathbb{R}^{(h_g+1)\times(w_g+1)}$ (`F.pad(p, (1, 0, 1, 0)).cumsum(0).cumsum(1)`) and evaluate all axis-aligned subwindows $B = [i_1, i_2) \times [j_1, j_2)$ via `torch.triu_indices(..., offset=1)` with mass $p(B) \in [0, 1]$ and area fraction $a(B) = \frac{(i_2 - i_1)(j_2 - j_1)}{N}$. Over $\mathcal{B} = \{B : p(B) > a(B) + \epsilon_k \;\wedge\; \epsilon_k \le a(B) \le 0.5\}$, maximize $J(B) = p_{\text{cl}} \ln(p_{\text{cl}} / a_{\text{cl}}) - (p_{\text{cl}} - a_{\text{cl}})$ ($p_{\text{cl}} = \text{clamp}(p(B), \epsilon_k, 1.0)$, $a_{\text{cl}} = \text{clamp}(a(B), \epsilon_k, 1.0)$). If $J^* \le \epsilon_k$, return `((0, 0, h_g, w_g), 0.0, 1.0, 1.0)`; else return `(box_star, j_star, mass_star, area_star)`.
  - `NEVFEEngine.foveate(self, optical_energy: torch.Tensor, patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None) -> Tuple[Tuple[int, int, int, int], float, torch.Tensor]` runs **(Eq. 1)** with `(gamma_param=self.gamma_param, comp_a=self.comp_a)`, **(Eq. 2)** with `comp_b=self.comp_b`, and **(Eq. 3)**, returning `(box, j_star, p_post)`.

- **(Eq. 4) `112px`-Gated `25%`-Seam-Overlapped Exact `1:1` Square Sub-Tile Planner (`plan_isotropic_strip_boxes`)**:
  Signature: `plan_isotropic_strip_boxes(bbox: Tuple[int, int, int, int], img_size: Tuple[int, int], patch_stride: float, max_tiles: int = 2 + 1, comp_c: bool = True, eps: float = 1e-6) -> Tuple[List[Tuple[int, int, int, int]], Tuple[int, int], float]`.
  - Unpack `w_r, h_r = img_size`; let $W = \text{int}(w_r)$, $H = \text{int}(h_r)$. Return `[], (1, 1), 0.0` if $W \le 0$, $H \le 0$, or `int(max_tiles) <= 0`. Unpack `bx1_i, by1_i, bx2_i, by2_i = bbox`, clamp inside `[0, W] x [0, H]` with spans $\Delta_x = \max(\min(2.0, W), \, \min(W, cx_2 - cx_1))$, $\Delta_y = \max(\min(2.0, H), \, \min(H, cy_2 - cy_1))$, and $s_p = \max(1.0, \text{float}(patch\_stride))$.
  - Set sub-tile stride factor $\sigma_{\text{step}} = 1.0 - 0.5 \cdot 0.5 = 0.75$ (`25%` seam overlap; `zhang2019making` p. 3, `dong2016srcnn` p. 3) if `comp_c` else $1.0$ (`0%` seam overlap), and **unconditional** multi-tile minimum span $d_{\min} = (2.0 + 2.0)\,s_p$ (`112 px` across all 4 masks, matching `0f8a2d4d`'s `min_tile_dim` and preventing dense-scene over-tiling; `singh2021textocr` p. 2).
  - Candidate grids: $\mathcal{G} = \{(1, 1)\} \cup (\{(2, 1), (1, 2)\} \text{ if } \text{max\_tiles} \ge 2) \cup (\{(2 + 1, 1), (1, 2 + 1)\} \text{ if } \text{max\_tiles} \ge 2 + 1) \cup (\{(2, 2)\} \text{ if } \text{max\_tiles} \ge 2 + 2)$.
  - *Admissibility & Aspect Selection*: With $f_x(g_x) = 1.0 + \sigma_{\text{step}}(g_x - 1)$ and $f_y(g_y) = 1.0 + \sigma_{\text{step}}(g_y - 1)$, $(g_x, g_y) \in \mathcal{G}_{\text{adm}}$ iff $(g_x == 1 \vee \Delta_x \ge f_x(g_x)\,d_{\min}) \wedge (g_y == 1 \vee \Delta_y \ge f_y(g_y)\,d_{\min}) \wedge f_x(g_x)\,s_p \le W + \epsilon \wedge f_y(g_y)\,s_p \le H + \epsilon$ (fallback $\mathcal{G}_{\text{adm}} \leftarrow \{(1, 1)\}$ if empty). Select $(g_x^*, g_y^*) = \arg\min_{(g_x, g_y) \in \mathcal{G}_{\text{adm}}} \big(|\ln(\max(\epsilon, \Delta_x) / \max(\epsilon, \Delta_y)) - \ln(f_x(g_x) / f_y(g_y))|, \; g_x g_y\big)$.
  - *Unconditional `56px` Nyquist Floor & Exact `1:1` Square Sub-Tiles (`shi2017crnn` p. 3, `wang2021hrnet` p. 2)*: With $f_x = f_x(g_x^*)$, $f_y = f_y(g_y^*)$, and $s_{\text{fl}} = \min(2.0\,s_p, \min(W, H))$ (`56 px` -> `8.00x` zoom on `<4px` `CLASS_A` loci), compute $s_{\text{unit}} = \min\!\big(\max(\Delta_x / f_x, \, \Delta_y / f_y, \, s_{\text{fl}}), \; W / f_x, \; H / f_y\big)$, exact integer square side $s_{\text{int}} = \max(1, \min(W, H, \text{int}(\text{round}(s_{\text{unit}}))))$, enclosing strip dimensions $S_x = \min(W, \max(\text{float}(s_{\text{int}}), s_{\text{unit}} f_x))$, $S_y = \min(H, \max(\text{float}(s_{\text{int}}), s_{\text{unit}} f_y))$, in-bounds origin $sx_1 = \max(0.0, \min(W - S_x, 0.5(cx_1 + cx_2 - S_x)))$, $sy_1 = \max(0.0, \min(H - S_y, 0.5(cy_1 + cy_2 - S_y)))$, and step $(\delta_x, \delta_y) = \big((S_x - s_{\text{int}}) / \max(1, g_x^* - 1) \text{ if } g_x^* > 1 \text{ else } 0.0, \; (S_y - s_{\text{int}}) / \max(1, g_y^* - 1) \text{ if } g_y^* > 1 \text{ else } 0.0\big)$. For $t_y \in \{0, \dots, g_y^* - 1\}, t_x \in \{0, \dots, g_x^* - 1\}$, compute $x_0 = \max(0, \min(W - s_{\text{int}}, \text{int}(\text{round}(sx_1 + t_x \delta_x))))$, $y_0 = \max(0, \min(H - s_{\text{int}}, \text{int}(\text{round}(sy_1 + t_y \delta_y))))$, append exact square box `(x_0, y_0, x_0 + s_int, y_0 + s_int)`, and return `(boxes, (gx_s, gy_s), float(s_int))`.

### 4.3 Retained Baseline Single-Step `IG-VFED` Equations (`t = 1` vs. `t > 1` & Decoupled Stage-A Ablation)
- **(Eq. 5) Mean-Field Visual Reference (`compute_mean_field_reference_embeddings`)**:
  For `effective_vit` $V_{\text{eff}} \in \mathbb{R}^{N_{\text{eff}} \times P_{\text{tile}} \times D}$ (`dim() == 2 + 1`) or 2D `[P, D]` (`dim() == 2`), $V^0 = \mathbf{1} \bar{\boldsymbol{v}}^\top$ via spatial mean over `dim=(0, 1)` (or `dim=0` for 2D).
- **(Eq. 6) Bhattacharyya Coefficient & Geodesic Coupling (`compute_bhattacharyya_coefficient`, `compute_dynamic_coupling`)**:
  Promoting `logits_plus`, `logits_zero` to `float32`, $p_t^+ = \text{Softmax}(z_t^+)$, $p_t^0 = \text{Softmax}(z_t^0)$, $\text{BC}_t = \text{clamp}\big(\sum_{w=1}^{V} \sqrt{\max(0.0, p_{t,w}^+ p_{t,w}^0)}, \, 0.0, \, 1.0\big)$. For standalone `NEVFEEngine.decode_step` (preserving `148f870` `<= 1e-7` parity across all 8 masks in `test_01..test_15`): if $\neg d_a$, $\alpha_t = \lambda$; else $\alpha_t = \lambda \sqrt{\text{clamp}(1.0 - \text{BC}_t^2, 0.0, 1.0)} + \mathbb{I}[t == 1 \wedge d_c] \, \lambda \, \text{BC}_t$.
- **(Eq. 7) Dynamic Plausibility Truncation & Argmax (`compute_dynamic_plausibility_floor`, `nevfe_step_logits`)**:
  $\beta_t = \text{clamp}(\beta \cdot \text{BC}_t, 0.0, 1.0)$ if $d_b$ else $\beta$; $\tilde{z}_t = z_t^+ + \alpha_t (z_t^+ - z_t^0)$; $z_t^{\text{steer}}(w) = \tilde{z}_t(w)$ if $p_t^+(w) \ge \beta_t \max_u p_t^+(u)$ else $-10^9$; $\hat{y}_t = \arg\max_w z_t^{\text{steer}}(w)$ (returning `[B, 1]` `alpha_t` and `entropy_nats` on 2D `[B, V]` inputs, squeezed to `[1]` on 1D `[V]` inputs). Inside `VinternNEVFEAdapter.generate`, `nevfe_step_logits` is invoked with **locked `(comp_a=True, comp_b=True, comp_c=True)`** at every step $t \ge 1$ so `NEVFEPipeline.set_ablation_switches` cleanly ablates **only** the three orthogonal `SKS-OIF` Domain 1 optical components (`comp_a`, `comp_b`, `comp_c`) with zero double-bundling, while standalone `NEVFEEngine.decode_step` retains `(self.comp_a, self.comp_b, self.comp_c)`. Both `NEVFEEngine.set_ablation_switches` and `NEVFEPipeline.set_ablation_switches` preserve `gamma_param`.
