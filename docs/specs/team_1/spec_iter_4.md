### 4.2 Core Variational Manifold Foveation Equations (`src/nevfe/core/engine.py`)

- **Shared Centered Spherical Patch Representation (`_compute_centered_patch_sphere`)**:
  Given 3D `patch_embeds` $V \in \mathbb{R}^{H_g \times W_g \times D}$ (`tau_v: float = 1e-6`), sanitize $V$ via `torch.nan_to_num(patch_embeds.float(), nan=0.0, posinf=0.0, neginf=0.0)`, apply global peak scaling $\tilde{V} = V / \max(1.0, \max |V|) \in [-1.0, 1.0]$, subtract the spatial register/anisotropy centroid $\bar{V} = \frac{1}{H_g W_g}\sum_{u \in \Omega} \tilde{V}(u)$ (`darcet2024registers`, `mu2018allbutthetop`), form $\Delta \tilde{V}(u) = \tilde{V}(u) - \bar{V}$ with Euclidean norm $r_V(u) = \|\Delta \tilde{V}(u)\|_2$, and apply dimension-scaled `float32` ULP gate $\tau_D = \tau_v \cdot (\text{float}(\max(1, D)))^{0.5}$:
  $$\hat{V}(u) = \begin{cases} \dfrac{\Delta \tilde{V}(u)}{\max\big(r_V(u), \, \tau_D\big)} & \text{if } r_V(u) > \tau_D \\ \mathbf{0}_D & \text{otherwise} \end{cases} \in \mathbb{R}^{H_g \times W_g \times D}$$

- **(Eq. 1) KL-Specificity Exponential-Family Cross-Modal Lexical Anchor (`compute_lexical_spatial_distribution`)**:
  Signature: `compute_lexical_spatial_distribution(patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None, comp_a: bool = True, tau_v: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`. Require `patch_embeds.dim() == 3` (`ValueError` otherwise); let $(H_g, W_g, D) = \text{patch\_embeds.shape}$, $N = H_g W_g$, and $u_0 = \frac{1.0}{\max(1, N)} \mathbf{1}_{H_g \times W_g}$. If `query_embeds` is a 2D tensor with `query_embeds.shape[1] != D`, raise `ValueError`.
  - *Boundary condition (`query_embeds is None`, `.dim() != 2`, $M == 0$, $D == 0$, or $N \le 1$)*: Return exact uniform `unif` $u_0$ (`[H_g, W_g]`).
  - Otherwise, compute $\hat{V} \in \mathbb{R}^{H_g \times W_g \times D}$, sanitize `query_embeds` in `float32`, row-peak-scale $\tilde{E}_{Q,m} = E_{Q,m} / \max(1.0, \max_d |E_{Q,m,d}|)$, unit-normalize $\hat{E}_m = \tilde{E}_{Q,m} / \max(\|\tilde{E}_{Q,m}\|_2, \tau_v)$ when $\|\tilde{E}_{Q,m}\|_2 > \tau_v$ else $\mathbf{0}_D$, and form the cross-modal cosine matrix $S = \hat{V}_{\text{flat}} \hat{E}_Q^\top \in [-1, 1]^{N \times M}$.
  - *Leave-One-Out branch (`not comp_a`)*: Evaluate unweighted max-pooled lexical alignment $c_Q(u) = \max_{1 \le m \le M} S(u, m)$, $\Delta c_Q = c_Q - \text{mean}(c_Q)$, $\sigma_c = \sqrt{\max(0.0, \text{mean}(\Delta c_Q^2))}$, $z_c = \Delta c_Q / \max(\sigma_c, \tau_v)$ if $\sigma_c > \tau_v$ else $\mathbf{0}_N$, and return $\text{Softmax}(z_c).\text{view}(H_g, W_g)$.
  - *Full specificity branch (`comp_a == True`; `ethayarajh2019contextual`, `nielsen2013chernoff`)*: Center each token column $\Delta S(u, m) = S(u, m) - \frac{1}{N}\sum_{u'=1}^N S(u', m)$ and compute joint matrix dispersion $\sigma_S = \sqrt{\max(0.0, \text{mean}(\Delta S^2))}$. If $\sigma_S \le \tau_v$, return `unif`. Otherwise form standardized spatial potentials $Z = \Delta S / \max(\sigma_S, \tau_v) \in \mathbb{R}^{N \times M}$, per-token spatial posteriors $q_m = \text{Softmax}_{u \in \Omega}(Z(\cdot, m))$, and each token's **Spatial KL Information Gain** above uniform $u_0$:
    $$\mathcal{I}_m = \max\!\left(0.0, \; \sum_{u=1}^{N} \text{nan\_to\_num}\!\Big(q_m(u)\big(\ln q_m(u) + \ln N\big), \; \text{nan}=0.0, \, \text{posinf}=0.0, \, \text{neginf}=0.0\Big)\right), \qquad w_m = \frac{\mathcal{I}_m^2}{\sum_{m'=1}^{M} \mathcal{I}_{m'}^2}$$
    (returning `unif` if $\sum_{m'} \mathcal{I}_{m'}^2 \le \epsilon$). Pool natural parameters $\Phi_Q = Z w \in \mathbb{R}^N$, standardize $\Delta \Phi_Q = \Phi_Q - \text{mean}(\Phi_Q)$ by $\sigma_\Phi = \sqrt{\max(0.0, \text{mean}(\Delta \Phi_Q^2))}$ (returning `unif` if $\sigma_\Phi \le \tau_v$), and return $P_{\text{anchor}} = \text{Softmax}(\Delta \Phi_Q / \max(\sigma_\Phi, \tau_v)).\text{view}(H_g, W_g) \in \Delta^{N-1}$.

  Signature: `compute_manifold_markov_posterior(p_anchor: torch.Tensor, patch_embeds: torch.Tensor, gamma_param: Optional[float] = None, comp_b: bool = True, tau_v: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`.     $$\Big(I_N - (1.0 - r_N) K^\top\Big) P_{\text{conn}} = r_N \hat{P}_{\text{anchor}}, \qquad P_\gamma^* = (1.0 - \gamma_{\text{eff}}) \hat{P}_{\text{anchor}} + \gamma_{\text{eff}} \hat{P}_{\text{conn}} \in \Delta^{N-1}$$
