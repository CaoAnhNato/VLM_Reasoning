### 4.2 Core `WSR-MSF` Equations (`src/nevfe/core/engine.py`)

- **(Eq. 1) Diffusion-Free KL-Specificity Soft-`OR` Spatial Anchor (`compute_optical_anchor_posterior`)**:
  Signature: `compute_optical_anchor_posterior(patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None, comp_a: bool = True, tau_v: float = 1e-6, eps: float = 1e-12) -> torch.Tensor`.
  - Require `patch_embeds.dim() == 2 + 1` (else raise `ValueError`); let `(h_g, w_g, dim) = patch_embeds.shape`, $N = h_g w_g$, and $u_0 = \text{full}((h_g, w_g), \, 1.0 / \text{float}(\max(1, N)), \, \text{float32})$.
  - *Boundary conditions*: If `query_embeds is None` or `query_embeds.dim() != 2`, return $u_0$. If `query_embeds.shape[1] != dim`, raise `ValueError`. If `query_embeds.shape[0] == 0` or `dim == 0` or $N \le 1$, return $u_0$.
  - Sanitize $V_{\text{raw}} = \text{nan\_to\_num}(patch\_embeds.\text{float}(), \, 0.0, 0.0, 0.0).\text{view}(N, D)$ and $Q_{\text{raw}} = \text{nan\_to\_num}(query\_embeds.\text{float}(), \, 0.0, 0.0, 0.0)$. Peak-scale and center spatial anisotropy $\Delta\tilde{V} = \tilde{V} - \frac{1}{N}\sum_{u=1}^{N} \tilde{V}_u$ where $\tilde{V} = V_{\text{raw}} / \max(1.0, \max |V_{\text{raw}}|)$, and peak-scale each query row $\tilde{Q}_m = Q_{\text{raw},m} / \max(1.0, \max_d |Q_{\text{raw},m,d}|)$. Compute $r_V(u) = \|\Delta\tilde{V}_u\|_2$, $\tau_D = \tau_v \sqrt{\text{float}(\max(1, D))}$ (if $\max_u r_V(u) \le \tau_D$, return $u_0$), $r_E(m) = \|\tilde{Q}_m\|_2$, unit vectors $\hat{V}_u = \Delta\tilde{V}_u / \max(r_V(u), \tau_D)$ if $r_V(u) > \tau_D$ else $\mathbf{0}$ and $\hat{E}_m = \tilde{Q}_m / \max(r_E(m), \tau_v)$ if $r_E(m) > \tau_v$ else $\mathbf{0}$, and cross-modal cosine matrix $S = \hat{V} \hat{E}^\top \in [-1, 1]^{N \times M}$.
  - *Champion `0f8a2d4d` Fallback (`not comp_a`)*: Compute $c(u) = \max_{1 \le m \le M} S_{u,m}$, $\Delta c = c - \text{mean}(c)$, $\sigma_c = \sqrt{\max(0.0, \text{mean}(\Delta c^2))}$, and return $\text{Softmax}(\Delta c / \max(\sigma_c, \tau_v)).\text{view}(h_g, w_g)$ if $\sigma_c > \tau_v$ else $u_0$.
  - *KL-Specificity Soft-`OR` (`comp_a == True`; `radenovic2019finetuning`)*: Standardize each query token's spatial response across patches: $\Delta S_{u,m} = S_{u,m} - \frac{1}{N}\sum_{v=1}^{N} S_{v,m}$, $\sigma_m = \sqrt{\max(0.0, \frac{1}{N}\sum_{v=1}^{N} \Delta S_{v,m}^2)}$. If $\max_m \sigma_m \le \tau_v$, return $u_0$. Set $Z_{u,m} = \Delta S_{u,m} / \max(\sigma_m, \tau_v)$ if $\sigma_m > \tau_v$ else $0.0$, evaluate per-token spatial posterior $q_{u,m} = \text{Softmax}_{u}(Z_{u,m})$ and empirical spatial KL specificity $I_m = \max\!\big(0.0, \, \sum_{u=1}^{N} \text{nan\_to\_num}(q_{u,m}(\ln \max(q_{u,m}, \epsilon) + \ln N), \, 0.0, 0.0, 0.0)\big)$, form squared-KL weights $w_m = I_m^2 / \max(\sum_{k=1}^{M} I_k^2, \, \epsilon)$ (returning $u_0$ if $\sum_k I_k^2 \le \epsilon$), aggregate via shift-stabilized log-sum-exp Soft-`OR`:
    $$c_{\text{KL}}(u) = z_{\max}(u) + \ln \max\!\left(\epsilon, \; \sum_{m=1}^{M} w_m \exp\!\big(Z_{u,m} - z_{\max}(u)\big)\right), \qquad z_{\max}(u) = \max_{1 \le m \le M} Z_{u,m}$$
    and return $\text{Softmax}(\Delta c_{\text{KL}} / \max(\sigma_{\text{KL}}, \tau_v)).\text{view}(h_g, w_g)$ if $\sigma_{\text{KL}} > \tau_v$ else $u_0$, where $\Delta c_{\text{KL}} = c_{\text{KL}} - \text{mean}(c_{\text{KL}})$ and $\sigma_{\text{KL}} = \sqrt{\max(0.0, \text{mean}(\Delta c_{\text{KL}}^2))}$.

- **(Eq. 2) Diffusion-Free Conditional-Exterior Poisson-Bregman Locus Selection (`select_optical_foveal_loci` & `NEVFEEngine.foveate`)**:
  Signature: `select_optical_foveal_loci(posterior_2d: torch.Tensor, comp_a: bool = True, eps_k: float = 1e-6, eps: float = 1e-12) -> List[Tuple[Tuple[int, int, int, int], float, float, float]]`.

Sanitize $P = \text{nan\_to\_num}(posterior\_2d.\text{float}(), \, 0.0, 0.0, 0.0).\text{clamp}(\min=0.0)$. If $N == 0$, return `[((0, 0, h_g, w_g), 0.0, 0.0, 0.0)]`. Peak-scale $P \leftarrow P / \max(1.0, \max P)$, normalize onto $\Delta^{N-1}$ (uniform $1/N$ if sum $\le \epsilon$), and if $N \le 1$, return `[((0, 0, h_g, w_g), 0.0, 1.0, 1.0)]`.
  - Form 2D summed-area table $S \in \mathbb{R}^{(h_g+1)\times(w_g+1)}$ (`F.pad(p, (1, 0, 1, 0)).cumsum(0).cumsum(1)`) and evaluate all axis-aligned subwindows $B = [i_1, i_2) \times [j_1, j_2)$ via `torch.triu_indices(..., offset=1)` with mass $p(B) \in [0, 1]$ and area fraction $a(B) = \frac{(i_2 - i_1)(j_2 - j_1)}{N}$. Over $\mathcal{B}_1 = \{B : p(B) > a(B) + \epsilon_k \;\wedge\; \epsilon_k \le a(B) \le 0.5\}$, maximize $J_1(B) = p_{\text{cl}} \ln(p_{\text{cl}} / a_{\text{cl}}) - (p_{\text{cl}} - a_{\text{cl}})$ ($p_{\text{cl}} = \text{clamp}(p(B), \epsilon_k, 1.0)$, $a_{\text{cl}} = \text{clamp}(a(B), \epsilon_k, 1.0)$). If $J_1^* \le \epsilon_k$, return `[((0, 0, h_g, w_g), 0.0, 1.0, 1.0)]`; else set primary locus `b1 = (i1*, j1*, i2*, j2*)` (`bi1, bj1, bi2, bj2 = b1`) with `(p1, a1)`.
  - *Conditional-Exterior Secondary Locus (`comp_a == True`, $m_{\text{rem}} = 1 - p_1 > \epsilon_k$, $a_{\text{rem}} = 1 - a_1 > \epsilon_k$)*: Over strictly spatially disjoint boxes $\mathcal{B}_2(B_1^*) = \{B : (i_2 \le bi_1 \vee i_1 \ge bi_2 \vee j_2 \le bj_1 \vee j_1 \ge bj_2) \;\wedge\; p(B) > 2.0\,a(B) + \epsilon_k \;\wedge\; p_1 + p(B) > 0.5 \;\wedge\; \epsilon_k \le a(B) \le 0.5\,a_{\text{rem}}\}$, normalize conditional exterior mass $\tilde{p}(B) = \text{clamp}(p(B) / m_{\text{rem}}, \epsilon_k, 1.0)$ and exterior area $\tilde{a}(B) = \text{clamp}(a(B) / a_{\text{rem}}, \epsilon_k, 1.0)$, and maximize $J_2(B \mid B_1^*) = \tilde{p}\ln(\tilde{p} / \tilde{a}) - (\tilde{p} - \tilde{a})$. Append `(b2, j2_star, p2, a2)` iff $J_2^* \ge 0.5\,J_1^*$ and $J_2^* > \epsilon_k$. When `comp_a == False`, skip $\mathcal{B}_2$ so output is strictly 1-locus.
  - `NEVFEEngine.foveate(self, patch_embeds: torch.Tensor, query_embeds: Optional[torch.Tensor] = None) -> Tuple[List[Tuple[int, int, int, int]], float, torch.Tensor]` runs `(Eq. 1) -> (Eq. 2)` with `comp_a=self.comp_a` and returns `([loc[0] for loc in loci] if j1 > 1e-6 else [(0, 0, h_g, w_g)], j1, p_post)`.

- **(Eq. 3) `25%`-Seam-Overlapped ViT-Patch-Stride Multi-Strip Planner (`plan_overlapped_strip_boxes`)**:
  Signature: `plan_overlapped_strip_boxes(bbox: Tuple[int, int, int, int], img_size: Tuple[int, int], patch_stride: float, max_tiles: int = 2 + 1, comp_b: bool = True, eps: float = 1e-6) -> Tuple[List[Tuple[int, int, int, int]], Tuple[int, int], float]`.
  - Given `img_size = (W, H)`, return `[], (1, 1), 0.0` if $W \le 0$, $H \le 0$, or `max_tiles <= 0`. Clamp `bbox` inside `[0, W] x [0, H]` with spans $\Delta_x = \max(\min(2.0, W), \, \min(W, cx_2 - cx_1))$, $\Delta_y = \max(\min(2.0, H), \, \min(H, cy_2 - cy_1))$, and $s_p = \max(1.0, \text{float}(patch\_stride))$.
  - Set sub-tile stride factor $\sigma_{\text{step}} = 1.0 - 0.5 \cdot 0.5 = 0.75$ (`25%` seam overlap; `zhang2019making`, `dong2016srcnn`) if `comp_b` else $1.0$ (`0%` seam overlap), and candidate 1D strip grids $\mathcal{G} = \{(1, 1)\} \cup (\{(2, 1), (1, 2)\} \text{ if } \text{max\_tiles} \ge 2) \cup (\{(3, 1), (1, 3)\} \text{ if } \text{max\_tiles} \ge 3)$.
  - *Admissibility*: Define effective strip coverage factors $f_x(g_x) = 1.0 + \sigma_{\text{step}}(g_x - 1)$ and $f_y(g_y) = 1.0 + \sigma_{\text{step}}(g_y - 1)$.
    - If `comp_b == True`: $(g_x, g_y) \in \mathcal{G}_{\text{adm}}$ iff $(g_x == 1 \vee \Delta_x \ge f_x(g_x) s_p) \wedge (g_y == 1 \vee \Delta_y \ge f_y(g_y) s_p) \wedge f_x(g_x) s_p \le W + \epsilon \wedge f_y(g_y) s_p \le H + \epsilon$.
    - If `comp_b == False` (legacy `112 px` non-overlapped cap): $d_{\min} = (2.0 + 2.0) s_p$, and $(g_x, g_y) \in \mathcal{G}_{\text{adm}}$ iff $g_x \le \max(1, \lfloor \Delta_x / d_{\min} \rfloor) \wedge g_y \le \max(1, \lfloor \Delta_y / d_{\min} \rfloor)$.
    - Fallback $\mathcal{G}_{\text{adm}} \leftarrow \{(1, 1)\}$ if empty.
  - Select $(g_x^*, g_y^*) = \arg\min_{(g_x, g_y) \in \mathcal{G}_{\text{adm}}} \big(|\ln(\max(\epsilon, \Delta_x) / \max(\epsilon, \Delta_y)) - \ln(f_x(g_x) / f_y(g_y))|, \; g_x g_y\big)$.
  - With $f_x = f_x(g_x^*)$, $f_y = f_y(g_y^*)$, and sub-tile floor $s_{\text{fl}} = \min\!\big((2.0 \text{ if } \text{comp\_b} \text{ else } (2.0 + 2.0))\, s_p, \; \min(W, H)\big)$, compute isotropic unit side $s_{\text{unit}} = \min\!\big(\max(\Delta_x / f_x, \, \Delta_y / f_y, \, s_{\text{fl}}), \; W / f_x, \; H / f_y\big)$, enclosing strip dimensions $S_x = \min(W, \max(\Delta_x, s_{\text{unit}} f_x))$, $S_y = \min(H, \max(\Delta_y, s_{\text{unit}} f_y))$, in-bounds origin $sx_1 = \max(0.0, \min(W - S_x, 0.5(cx_1 + cx_2 - S_x)))$, $sy_1 = \max(0.0, \min(H - S_y, 0.5(cy_1 + cy_2 - S_y)))$, sub-tile size $(w_{\text{sub}}, h_{\text{sub}}) = (S_x / f_x, \, S_y / f_y)$, and step $(\delta_x, \delta_y) = \big((S_x - w_{\text{sub}}) / \max(1, g_x^* - 1) \text{ if } g_x^* > 1 \text{ else } 0.0, \; (S_y - h_{\text{sub}}) / \max(1, g_y^* - 1) \text{ if } g_y^* > 1 \text{ else } 0.0\big)$. Slice $g_x^* g_y^*$ integer boxes `(bx1_t, by1_t, bx2_t, by2_t)` inside `[0, W] x [0, H]` (`bx2_t >= bx1_t + 1`, `by2_t >= by1_t + 1`) and return `(boxes, (gx_s, gy_s), max(w_sub, h_sub))`.

- **(Eq. 4) Median-Noise-Gated MMSE Local-Wiener Achromatic Stroke Restoration (`_binomial_smooth_2d` & `restore_wiener_optical_strokes`)**:
  Signature: `restore_wiener_optical_strokes(rgb_chw: torch.Tensor, magnification: float = 2.0, gamma_param: Optional[float] = None, comp_c: bool = True, eps: float = 1e-12) -> torch.Tensor`.
  - Require `rgb_chw.dim() == 2 + 1` (`[C, H_t, W_t]`, else raise `ValueError`). Sanitize $I = \text{nan\_to\_num}(rgb\_chw.\text{float}(), \, \text{nan}=0.0, \text{posinf}=1.0, \text{neginf}=0.0).\text{clamp}(0.0, 1.0)$ with `(c_t, h_t, w_t) = I.shape`.
  - Resolve $\gamma_{\text{eff}} = \text{clamp}(\gamma, 0.0, 1.0)$ if `comp_c` else $0.0$ ($\gamma$ defaulting to `AlgorithmConfig().gamma_param` when `None`), $M_{\text{eff}} = \max(1.0, \text{float}(magnification))$, and bicubic interpolation footprint scale $\eta(M_{\text{eff}}) = 1.0 - 1.0 / M_{\text{eff}}^2 \in [0.0, 1.0)$.
  - *Boundary condition ($c_t == 0$, $h_t w_t \le 1$, or $\gamma_{\text{eff}}\,\eta(M_{\text{eff}}) \le \epsilon$)*: Return $I$ identically (`0.0` ULP perturbation when `comp_c == False`, $\gamma == 0.0$, $M_{\text{eff}} \le 1.0$, or $1\times 1$ / $0$-channel input).
  - Define $\mathcal{G}(X)$ as two passes of separable symmetric `[1, 2, 1] / 4` (`0.5 * 0.5`) reflection-padded 2D binomial smoothing (`zhang2019making`, `romano2017little`): along width when $w_t > 1$ using `cat([out[:, :, 1:2], out, out[:, :, w_t - 2 : w_t - 1]], dim=-1)`, and along height when $h_t > 1$ using `cat([out[:, 1:2, :], out, out[:, h_t - 2 : h_t - 1, :]], dim=1)` (exact no-op along any axis of length `1`).
  - Extract achromatic luminance $L = \frac{1}{c_t}\sum_{c=1}^{c_t} I_c \in [0, 1]^{1 \times H_t \times W_t}$, zero-phase RED Laplacian stroke detail $d = L - \mathcal{G}(L)$ (`romano2017little` p. 3), local detail energy $v_{\text{loc}} = \mathcal{G}(d^2) \ge 0$, robust stationary background noise floor $\nu_0 = \text{median}(v_{\text{loc}}) \ge 0$ (`zhang2017dncnn`), and MMSE local-Wiener shrinkage gain:
    $$g_W(x, y) = \frac{\max\!\big(0.0, \; v_{\text{loc}}(x, y) - 2.0\,\nu_0\big)}{v_{\text{loc}}(x, y) + 2.0\,\nu_0 + \epsilon} \in [0.0, 1.0)$$
    Inject the gated achromatic stroke residual identically across all channels (`0.0` opponent chromaticity shift `(R-G, G-B)` prior to clamping):
    $$\tilde{I}_c(x, y) = \text{clamp}\!\Big(I_c(x, y) + 2.0\,\gamma_{\text{eff}}\,\eta(M_{\text{eff}})\,g_W(x, y)\,d(x, y), \; 0.0, \; 1.0\Big)$$

### 4.3 Retained Baseline Single-Step `IG-VFED` Equations (`t = 1` vs. `t > 1` & Decoupled Stage-A Ablation)
- **(Eq. 5) Mean-Field Visual Reference (`compute_mean_field_reference_embeddings`)**:
  For `effective_vit` $V_{\text{eff}} \in \mathbb{R}^{N_{\text{eff}} \times P_{\text{tile}} \times D}$ (or 2D `[P, D]`), $V^0 = \mathbf{1} \bar{\boldsymbol{v}}^\top$ via spatial mean over `dim=(0, 1)` (or `dim=0` for 2D).
- **(Eq. 6) Bhattacharyya Coefficient & Geodesic Coupling (`compute_bhattacharyya_coefficient`, `compute_dynamic_coupling`)**:
  Promoting `logits_plus`, `logits_zero` to `float32`, $p_t^+ = \text{Softmax}(z_t^+)$, $p_t^0 = \text{Softmax}(z_t^0)$, $\text{BC}_t = \text{clamp}\big(\sum_{w=1}^{V} \sqrt{\max(0.0, p_{t,w}^+ p_{t,w}^0)}, \, 0.0, \, 1.0\big)$. For standalone `NEVFEEngine.decode_step` (preserving `test_01..test_15` backward compatibility): if $\neg d_a$, $\alpha_t = \lambda$; else $\alpha_t = \lambda \sqrt{\text{clamp}(1.0 - \text{BC}_t^2, 0.0, 1.0)} + \mathbb{I}[t == 1 \wedge d_c] \, \lambda \, \text{BC}_t$.
- **(Eq. 7) Dynamic Plausibility Truncation & Argmax (`compute_dynamic_plausibility_floor`, `nevfe_step_logits`)**:
  $\beta_t = \text{clamp}(\beta \cdot \text{BC}_t, 0.0, 1.0)$ if $d_b$ else $\beta$; $\tilde{z}_t = z_t^+ + \alpha_t (z_t^+ - z_t^0)$; $z_t^{\text{steer}}(w) = \tilde{z}_t(w)$ if $p_t^+(w) \ge \beta_t \max_u p_t^+(u)$ else $-10^9$; $\hat{y}_t = \arg\max_w z_t^{\text{steer}}(w)$. Inside `VinternNEVFEAdapter.generate`, `nevfe_step_logits` is invoked with **locked `(comp_a=True, comp_b=True, comp_c=True)`** at every step $t \ge 1$ so `NEVFEPipeline.set_ablation_switches` cleanly ablates **only** the three orthogonal `WSR-MSF` Domain 1 optical components (`comp_a`, `comp_b`, `comp_c`) with zero double-bundling, while standalone `NEVFEEngine.decode_step` retains `(self.comp_a, self.comp_b, self.comp_c)`. Both `NEVFEEngine.set_ablation_switches` and `NEVFEPipeline.set_ablation_switches` preserve `gamma_param`.
